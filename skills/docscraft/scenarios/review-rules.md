# 复查规则

## 何时用

规则越来越多、判断型规则过期、跨项目重复、准备上收 canon。

## 输入

- 规则目录
- 复查范围：全量 / 某领域
- 当前日期

## 步骤

1. 列出规则，标类型：事实 / 约束 / 判断。
2. 事实型：检查是否有生成源；手写的标“需生成”。
3. 约束型：检查是否有 lint / CI / 脚本；没有的降级为“建议”。
4. 判断型：检查 owner 与复核日期；过期的标“过期”，降级为“参考”。
5. 找跨项目重复：同一机制在第三个项目出现，评估上收 canon。
6. 找例外：是否有理由 / owner / 到期；安全红线不可豁免。
7. 找度量快照：改成查询命令。
8. 出复查报告与下一步。

## 输出

- 规则清单（类型 / 状态 / owner / 到期 / 检查方式）
- 过期 / 无主 / 无检查项
- Canon 候选
- 建议动作：续期 / 改写 / 删除 / 转机检

## 验收

- 每条判断型规则有 owner 与日期
- 每条约束型规则有检查入口
- 每条事实型规则有来源
- 过期项已降级
- 没有“永久例外”
- 不把判断型规则直接改成硬门禁
