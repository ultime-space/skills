# AI 上下文

> 用途：让 agent 在正确的上下文里工作，而不是靠猜、靠记忆、靠整仓扫描。
> 口径：入口短、正文稳、任务上下文按需；同一事实只留一份。

## 上下文分层

| 层 | 内容 | 加载时机 |
|---|---|---|
| Skill 描述 | name + description | 启动时常驻 |
| 项目入口 | `AGENTS.md` | 任务开始 |
| 领域规则 | `rules/<area>.md` | 命中领域时 |
| 参考文档 | `docs/` / API / 类型 | 需要细节时 |
| 任务上下文 | diff / 目标 / 验收 | 当前任务 |
| 过程记录 | 计划 / 进度 / ADR | 长任务按需 |

不要把所有层一次性塞进入口。入口只负责“告诉 agent 去哪读”。

## 推荐读顺序

1. 根 `README.md`：项目是什么、怎么跑
2. 根 `AGENTS.md`：先读顺序、红线、验证命令
3. 端 `AGENTS.md`：当前端 / 包的入口
4. 相关 `rules/`：只读与任务相关的领域
5. 相关 `docs/` / ADR：需要背景或决策时
6. 代码与测试：确认事实

读完后，agent 应能回答：

- 当前任务属于哪个领域？
- 哪条规则是硬约束，哪条是判断？
- 怎么验证完成？

## 入口写法

`AGENTS.md` 建议只包含：

```md
# <项目 / 端>

## 先读
1. ../README.md
2. rules/pages.md
3. rules/api.md

## 红线（≤12）
- 禁止页面直接 import api，因为请求 / 状态 / 转换会散落；反例：pages/home/index.vue。
- 禁止手改生成物，因为重生成会覆盖；反例：types/openapi.ts。

## 验证
- pnpm typecheck
- pnpm test
```

规则正文不要复制进来；用链接。

## 渐进披露

Skill 与文档都应该按需加载：

- `SKILL.md` 只写定位、路由、红线、输出格式
- 细则放 `docs/`，需要时再读
- 模板 / 示例放 `templates/`，执行时再取
- 长参考放独立文件，不塞进入口

判断方法：如果入口超过一屏，读者还没有开始任务，就已经迷路了。

## 激活与假阴性

Skill 不是“装上就自动生效”：

- `description` 要写清“什么时候用”，否则 agent 不会激活
- 项目 `AGENTS.md` 里留一句指针，降低漏读概率
- 任务里点名 skill（如“用 Docscraft 审计文档”）最稳
- 多个 skill 竞争时，description 要能区分边界

不能假设所有 agent 都会读同一个文件；入口要跟 agent 无关，平台差异交给适配层。

## 防 AI 漂移的四个动作

### 1. 先复述

改文档前，先用一句话复述：

- 范围：哪个目录 / 哪份文档
- 真源：以哪个文件为准
- 验收：跑什么命令 / 看什么结果

复述不出，说明上下文不够，先读入口。

### 2. 引用证据

每条结论给：

- 文件路径 + 行号
- 命令 + 结果
- 或明确的“待验证”

禁止“看起来”“应该是”“一般来说”。

### 3. 不造第二真源

- 不复制上游正文
- 不在 README 与 rules 各写一份
- 不手写可生成的事实
- 不把判断型规则写成硬门禁

### 4. 同步验证

改完必须：

- 更新入口 / 索引 / 链接
- 跑生成物比对（如有）
- 跑链接 / 术语 / 示例检查（如有）
- 报告“改了什么、为什么、怎么验、风险”

## 长任务

长任务不要靠模型记忆：

- 先写计划（范围 / 步骤 / 验收）
- 中途把关键决策写入 ADR 或进度记录
- 结束做一次收敛：实现 vs 计划 vs 文档是否一致
- 不把临时总结当成永久规范

## 多 agent / 多工具

- 入口用 `AGENTS.md` 这类通用格式，不绑定单一产品
- 平台专属入口只做指针，不复制正文
- 同一规则只维护一份；适配层只做格式转换
- 换 agent 时先跑一次“能否找到入口”的 smoke test

## 自检

- [ ] 入口能在一屏内说清“先读什么”
- [ ] 红线 ≤12 条，且每条可判决
- [ ] 规则正文不在入口里重复
- [ ] `description` 能区分本 skill 与相邻 skill
- [ ] 长任务有计划 / 进度 / 收敛
- [ ] 结论有文件、命令或“待验证”标记
- [ ] 没有把整仓文档塞进上下文

## 反模式

- `AGENTS.md` 写成一万字规范
- 每个 agent 各维护一份规则正文
- 只写“要遵守规范”，不写去哪读
- 让 AI 凭记忆补类型 / 字段 / 命令
- 任务结束不做实现与文档的收敛
