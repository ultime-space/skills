# 原则

> 用途：Docscraft 的底层判据。规则冲突时，以本文件为准。
> 范围：仓库文档与 AI 上下文；不涉及代码架构与业务设计。

## 1. 单一真源

一条事实只保留一份正文。其它位置只允许：

- 指针：路径 / 链接 / 一句定位
- 差异：本项目与上游不同之处
- 决策：ADR 记录为什么选这个方案

判断方法：如果同一个事实可以在两处被修改，它就已经漂移了。

## 2. 读者分层

| 读者 | 入口 | 要回答 |
|---|---|---|
| 人 | `README.md` | 这是什么、怎么跑、目录怎么走、怎么贡献 |
| agent | `AGENTS.md` | 先读什么、红线是什么、怎么验证 |
| 维护者 | `rules/` + `docs/` | 细则、边界、决策、历史 |
| 外部使用者 | 公开文档 / `llms.txt` | 怎么用、有哪些能力、去哪查 |

同一段内容不要同时服务三种读者；宁可拆成入口 + 指针。

## 3. 入口与正文分离

入口只做三件事：

1. 说明“先读哪几个文件”
2. 列出不可违反的红线（建议 ≤12 条）
3. 给出验证命令

正文留在 `rules/`、`docs/`、ADR。入口里不复述正文；正文里不重复入口。

## 4. 事实生成、约束机检、判断留人

| 类型 | 例子 | 维护方式 |
|---|---|---|
| 事实型 | props、API 形状、目录清单、类型字段 | 从源码 / 类型 / 配置生成；禁止手写 |
| 约束型 | 命名、依赖方向、禁用 API | lint / CI / 脚本；没被检查等于不存在 |
| 判断型 | 分层取舍、抽象时机、例外是否合理 | owner + 复核日期；到期降级为“参考” |

一条规则只能属于一类；混合类型要拆开。

## 5. 规则可过期

- 判断型规则必须有 owner 与复核日期。
- 到期未复核，自动降级为“参考”，不再作为硬性要求。
- 事实型规则不需要日期，但必须有生成来源。
- 约束型规则不需要日期，但必须有检查入口。

没有 owner 的规则，等于没有责任人。

## 6. 同变更同步

改动涉及以下任一情况时，代码与文档必须同一个变更：

- 新增约定
- 修改现有模式
- 废弃旧做法
- 修改生成源 / 生成物
- 修改入口或目录结构

不允许“代码先合，文档后补”；补的那次通常不会发生。

## 7. 可验证

每份关键文档至少有一种验证方式：

- 命令：构建 / 测试 / typecheck / 生成
- 链接：死链检查
- 生成物：重新生成后 diff 为空
- 示例：可执行 / 可复现
- 规则：lint / CI
- 判断：owner 复核记录

没有验证方式的文档，只能算草稿。

## 8. 不写度量快照

不要写“某属性共 81 处”“页面共 23 个”这类会过期的数字。

写查询命令或检索式，让读者自己得到当前值：

```bash
rg -n "pattern" src
```

需要趋势或阈值时，写“怎么算”，不写“当时是多少”。

## 9. Canonical link 优先

上游 / 外部已有的正文：

- 用链接指向 canonical 来源
- 只写本地差异、版本要求、例外
- 不复制整段正文

双份正文的维护成本翻倍，过期速度也翻倍。

## 10. 本地调研不进仓库

调研、对比、个人笔记属于过程材料：

- 放本地目录（如 `.local/notes/`），不进 git
- 结论进入 `docs/` / `rules/` 后，本地只留出处与推导
- 不把客户名、内部路径、个人工具路径带进公开文档

## 11. 术语与命名写法

- AI 面向文档（`docs/` / `scenarios/` / `prompts/` / `templates/`）英文裸写；`README`、对外报告首次出现用 `English（中文）`。
- 名字类不附中文：产品 / 文件 / 命令 / 语言 / 框架 / 标准名 / 代码标识（如 Docscraft、README.md、npm、JS/TS、JSON）。
- 术语表见 `07-glossary.md`；`tests/terms.test.mjs` 检查术语表与 README 首次出现，漏加即失败。

## 每个文档先回答三问

1. **谁读？** 人 / agent / 维护者 / 外部使用者
2. **读完要做什么？** 跑命令 / 改代码 / 做决策 / 查事实
3. **过期怎么发现？** 生成 / 检查 / owner / 链接

三问答不出来，就不要新增文档；先合并到现有入口。

## 反模式

- README 与 rules 各写一份同一规则
- AGENTS.md 塞满细则，agent 读不完
- 事实型字段手写在文档里，源码改了文档不改
- 判断型规则没有 owner，过期后还在当硬门禁
- 文档里写“目前共 N 处”，一周后失真
- 复制上游文档，改了一处漏一处
- 用 `.agents/rules/` 当正文，换 agent 后失效
- 文档与代码分两个 PR，后一个永远迟到
