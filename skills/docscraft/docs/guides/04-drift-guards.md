# 防漂移

> 用途：让文档、规则、决策、链接和示例保持与实现一致。
> 口径：能机检的机检，不能机检的写 owner 与复核方式。
> 交付前逐条自检：`docs/contracts/08-checklist.md`。

## 漂移类型

| 类型 | 表现 | 首选检查 |
|---|---|---|
| 事实漂移 | 字段名、类型、默认值、目录清单过期 | 从源码 / 类型 / 配置生成 |
| 结构漂移 | 文档路径变了，入口 / 链接没变 | 链接检查 + 入口 smoke test |
| 规则漂移 | 规则写了但没人执行；或执行了但规则没更新 | lint / CI + 规则到期表 |
| 决策漂移 | ADR 说 A，代码做 B，规范又写 C | 决策复核 + 实现收敛 |
| 链接漂移 | 死链、重定向、私有路径外泄 | 链接检查 + 路径白名单 |
| 生成物漂移 | 手改生成物，重生成后被覆盖 | 重新生成 diff |
| 示例漂移 | 示例命令 / 代码跑不通 | 示例执行 / doctest |
| 术语漂移 | 同一概念多种叫法 | prose lint / 术语表 |

## 最小防线

### 1. 单一真源

- 一条事实只留一份正文
- 入口只放指针
- 上游内容用 canonical link
- 发现双份正文，先合并再新增

### 2. 事实生成

事实型内容不要手写：

- 类型 / 字段 / props / API 形状从源码生成
- 目录清单用脚本生成
- 版本 / 命令从配置读取
- 生成物标“勿手改”，并做重生成 diff

### 3. 约束机检

约束型规则必须落到检查：

- lint / typecheck / 单测
- 目录 / 依赖边界脚本
- 禁用 API / 命名的自定义规则
- CI 里失败即阻断

没被检查的约束，只能写成“建议”，不能写成硬性规则。

### 4. 链接与路径

- CI 跑死链检查（Markdown / HTML / 内部相对链接）
- 公开文档禁止内部路径 / 主机名 / 私有仓库链接
- 旧路径迁移时保留一次重定向说明，下个版本删除

### 5. 示例验证

- 命令示例定期执行
- 代码示例尽量可复制运行
- 生成物示例标明来源与版本
- 无法执行的示例标“示意”，不冒充可运行

### 6. 文档与代码同变更

- 新增 / 修改 / 废弃约定时，文档与代码同一个 PR
- 修改生成源时，同时更新生成物与说明
- 修改目录时，同时更新入口与索引
- 不允许“先合代码，文档后补”

### 7. Owner 与到期

- 判断型规则写 owner + 复核日期
- 到期未复核，降级为“参考”
- 事实型规则跟生成源绑定
- 约束型规则跟检查入口绑定

### 8. 收敛检查

中大型变更结束前做一次：

- 规格 / 计划 / 任务 / 实现是否一致
- 规范 / ADR / README 是否同步
- 有没有新增第二真源
- 有没有未登记的例外

## 推荐 CI 组合

| 检查 | 作用 | 频率 |
|---|---|---|
| 链接检查 | 死链 / 失效入口 | 每次 PR |
| 生成物 diff | 手改 / 过期生成物 | 每次 PR |
| lint / typecheck | 约束型规则 | 每次 PR |
| 示例执行 | 命令与代码片段 | 每次 PR 或定时 |
| 规则到期 | 判断型规则过期 | 每周 / 每月 |
| 入口 smoke test | agent 能否找到入口 | 版本发布前 |
| golden tasks | agent 是否按文档工作 | 版本发布前 |

不必一次上全；先上“链接 + 生成物 + 一个最关键约束”。

## 审计方法

1. 画文档地图：入口、正文、决策、生成物、索引。
2. 标出每个事实的唯一来源；找不到来源的标“待确认”。
3. 找双份正文：同一段话出现两次以上。
4. 找过期：字段 / 命令 / 数字 / 链接。
5. 找无主规则：判断型但无 owner / 日期。
6. 找未执行约束：写了“必须”，但 CI 没有检查。
7. 出最小修复计划：先修入口与错误事实，再合并重复。

## 假安全感

以下情况不代表文档没问题：

- 链接全绿，但事实过期
- lint 通过，但规则本身写错
- 生成物 diff 为空，但生成源错了
- README 很长，但 agent 找不到入口
- golden task 通过一次，但换项目就失效

机检只覆盖“已编码的规则”；语义、结构、决策仍需人判断。

## 反模式

- 文档和代码两个 PR
- 手改生成物，靠 review 记住
- 链接检查忽略太多域名
- 规则到期没人管
- 用“最新”“目前”代替版本 / 日期
- 只写“保持一致”，不写怎么检查
