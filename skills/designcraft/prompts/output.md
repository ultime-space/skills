# 输出格式

## 评审报告

1. **结论**：通过 / 需调整 / 无法判定。
2. **判据**：引用 `docs/typography.md` 或 `docs/color.md` 的规则；不引用就不算规范。
3. **证据**：原值、合成后的值、实测对比度、目标与门槛。
4. **最近可行档**：档位、偏差、代价；没有就写「需要上层覆盖」。
5. **风险**：未知底、模式嵌套、放大 / 窄视口 / 译文增长。

## 规则

- 不写实现状态（哪些已落码以 roadmap 为准）。
- 不写度量快照；写查询命令或复算方式。
- 给不出判据的结论标「偏好」，不写成规范。
- core 合同与项目自检分开写；不把「core 通过」当成「页面合格」。
- 不复制源正文；需要时给链接与差异。
