# 表面与光影评审

## 目标

判断面阶、半透明、分块策略、遮罩、未知底与材质边界是否成立；光影方向、阴影、环境遮蔽、边缘高光与明暗是否一致。不在时给出最近可行方案。

## 输入

- 页面 / 组件 / 设计值表；需要时附截图与背景说明。
- 先确认模式（浅 / 深 / 局部）、分块策略（tonal / outline / elevated）与是否存在未知底。

## 步骤

1. **一级面容器**：画布、输入框、浮层主要内容、直接放在复杂背景上的卡片 / 面板；半透明是否按最坏背景验证合成对比度；底不可控时是否有底衬 / 遮罩 / 回退。
2. **面阶**：抬升 / 浮层 / 凹陷是否落在目标关系（1.10 / 1.14 / 1.07）；是否用整元素透明度冒充面阶。
3. **半透明用途**：面阶 tint、墨块、状态层、遮罩、阴影墨量是否混用。
4. **分块**：同一层级是否只有一种边界手段；是否出现底色 + 描边 + 阴影三层叠。
5. **遮罩**：是否全区域半透明背景色；是否被拿去当环境遮蔽；容器边缘是否另有环境遮蔽 / 边缘高光。
6. **未知底**：图片 / 视频 / 渐变 / 多层透明是否给了局部实色底衬、不透明面或经验证的遮罩。
7. **光源**：是否只有一个全局方向；高光是否同源；Frame / 浮层容器是否没有第二盏灯。
8. **阴影**：档位与槽位是否来自设计值；浮层容器是否误用方向阴影。
9. **边缘高光 / 明暗**：是否来自设计值；浅色下不可见时是否用遮光或面差补足。
10. **深浅**：去掉阴影后靠面差 + 边缘高光是否仍能读出层级；强制颜色 / 打印是否退化。
11. **性能**：模糊半径、覆盖面积、层数、是否动画；是否对阴影做过渡。

## 输出

按 [`prompts/output.md`](../prompts/output.md)：

- 结论（通过 / 需调整）
- 每条判据与证据（原值 → 目标 → 偏差）
- 风险（未知底、深色可见性、性能、强制颜色）
- 不把「有阴影」当成「有层级」

## 反例

- 卡片同时用底色阶、描边和阴影。
- 用整元素 `opacity` 表达面阶。
- 把遮罩当环境遮蔽，或把边缘高光当描边。
- 深色靠加重阴影分层，结果几乎不可见。
- 高光方向与阴影方向不一致。
- 透明输入框直接放在图片 / 渐变 / 复杂背景上，未验证最坏背景对比度，也没有底衬 / 遮罩 / 回退。
- 半透明浮层 / 抽屉承载正文 / 表单，未验证合成对比度或没有回退。
