# 表面与光影评审

## 目标

判断面（层级 / 填充 / 形态）、半透明、分块策略、遮罩、未知底与材质是否成立；两套光系统的五个光槽是否一致。不在时给出最近可行方案。

## 输入

- 页面 / 组件 / 设计值表；需要时附截图与背景说明。
- 先确认模式（浅 / 深 / 局部）、分块策略（tonal / outline / elevated）与是否存在未知底。

## 步骤

1. **一级面容器**：画布、输入框、浮层主要内容、直接放在复杂背景上的卡片 / 面板；半透明是否按最坏背景验证合成对比度；底不可控时是否有底衬 / 遮罩 / 回退。
2. **面阶**：抬升 / 浮层 / 凹陷是否落在目标关系；是否用整元素透明度冒充面阶。
3. **形态**：每个面是否声明了平面 / 凸起 / 凹陷；平面元素是否被误加了高光或明暗。
4. **半透明用途**：面阶 tint、墨块、状态层、遮罩、投影墨量是否混用。
5. **分块**：同一层级是否只有一种边界手段；是否出现底色 + 描边 + 投影三层叠。
6. **遮罩**：是否全区域半透明背景色；是否被拿去当环境遮蔽；容器边缘是否另有环境遮蔽 / 环境高光。
7. **未知底**：图片 / 视频 / 渐变 / 多层透明是否给了局部实色底衬、不透明面或经验证的遮罩。
8. **光源**：是否只有一个全局方向；环境光是否无方向；是否出现第二盏灯。
9. **光槽**：两个高光槽是否在内侧；受光边是否跟方位角；方向高光是否配了可辨的环境底；光色是否只有主光 / 环境两个来源。
10. **投影与环境遮蔽**：档位是否来自设计值；投影是否只给离开底面的元素；遮蔽是否只给贴近底面的元素；浮层容器是否误用方向投影。
11. **深浅**：去掉投影后靠面差 + 高光是否仍能读出层级；强制颜色 / 打印是否退化。
12. **性能**：模糊半径、覆盖面积、层数、是否动画；是否对投影做过渡。

## 输出

按 [`prompts/output.md`](../prompts/output.md)：

- 结论（通过 / 需调整）
- 每条判据与证据（原值 → 目标 → 偏差）
- 风险（未知底、深色可见性、性能、强制颜色）
- 不把「有阴影」当成「有层级」

## 反例

- 卡片同时用底色阶、描边和投影。
- 平面元素加了高光，却没有厚度。
- 方向高光没有环境底，圆角处看起来断开。
- 给高光单独配了一个角度，和投影方向不一致。
- 同一场景出现两枚阴影墨，暗侧偏纯黑。
- 用整元素透明度表达面阶。
- 把遮罩当环境遮蔽，或把环境高光当描边。
- 深色靠加重投影分层，结果几乎不可见。
- 透明输入框直接放在图片 / 渐变 / 复杂背景上，未验证最坏背景对比度，也没有底衬 / 遮罩 / 回退。
- 半透明浮层 / 抽屉承载正文 / 表单，未验证合成对比度或没有回退。
