# 参考已有风格复刻

## 目标

参考一个已有风格（截图、产品、样例）复刻到当前设计系统：先提炼风格特征，再映射到既有维度，最后检查交互逻辑。只提取维度取向与关系，不搬具体值；不新增风格专用设计值。

## 输入

- 参考对象：截图 / 页面 / 产品，说明复刻范围（整页 / 局部 / 单个组件）。
- 当前系统的维度与档位；没有就标注未知。
- 约束：平台、性能、无障碍、品牌资产、必须保留的骨架。
- 最坏内容：长文、空态、错误、窄屏。

## 步骤

1. **提炼风格特征**：按骨架、材质、光影、排版、密度五项写参考对象的选择；只写关系与取向，不抄数值、字体名或类名。
2. **映射维度**：把特征映射到当前系统的既有维度（颜色、排版、形状、表面 / 光影、动效、状态、布局、密度）；标出哪些能表达、哪些只是偏好。
3. **检查交互逻辑**：先判断参考对象的层级与交互是否自洽——主面板 / 导航 / 表单是不是同一张纸面；凹凸方向是否与光影系统一致；按压 / 焦点 / 禁用是否同源。交互逻辑不成立时，先修逻辑，不调数值。
4. **归因差异**：每个差异归到四类之一——交互逻辑不成立、参数 / 档位不对、组合 / 配方不对、当前系统缺层。缺层只登记，不直接新增设计值。
5. **给复刻页**：用当前系统的骨架搭一个代表性页面或分区，覆盖默认、hover、焦点、按下、禁用与一个最坏内容场景。
6. **给差异清单与结论**：逐项写参考、当前、归因、影响面、代价；结论只到「可复刻 / 需补能力 / 不建议复刻」。

## 输出

- 风格特征表（骨架 / 材质 / 光影 / 排版 / 密度）
- 维度映射表（特征 → 维度 → 现有取值 / 角色 → 能否表达）
- 交互逻辑结论（成立 / 哪一条不成立）
- 差异清单（归因：逻辑 / 参数 / 组合 / 缺层）
- 复刻页与最坏内容说明
- 缺口清单（只登记，不新增设计值）

## 禁止

- 照抄参考对象的色值、字号、字体名、类名或组件代码。
- 把「像」当成验收标准；不以逐值相等作为通过条件。
- 为复刻新增风格专用设计值、维度或第二套骨架。
- 用低对比、隐藏焦点或去掉状态来表达「更接近参考」。
- 把偏好当规范结论；规范下限仍按现有报告。
