# 配置品牌色

## 目标

判断一个品牌色能否在浅 / 深两端同时满足实心面上的文字目标 `4.5`，并给出可操作的调整建议。

## 输入

- 品牌色相、锚点明度、彩度系数（或一个候选 hex）。
- 前景方向：浅色模式近白字、深色模式近黑字；不做自动推断。
- 是否允许降彩度 / 调明度 / 换邻近色相。

## 步骤

1. 浅色端：白字 4.5 要求填充相对亮度 **≤ 0.183**。
2. 深色端：黑字 4.5 要求填充相对亮度 **≥ 0.175**。
3. `0.175–0.183` 是死区，两头都不达标；品牌色落在这里必须调整。
4. 保持色相，先调明度，再降彩度；色域不够时只降彩度，不降明度。
5. 输出状态：`ok` / `chroma-reduced` / `warn` / `unreachable`。
6. 给具体建议：明度 ±、彩度降多少、色相 ±15°；同时给两端各自的可达值。

## 输出

按 [`templates/brand-color-check.md`](../templates/brand-color-check.md) 填表：

- 两端填充 / 文字 / 实测对比度
- 需要的明度 / 彩度调整
- 是否有死区风险
- 是否建议换色相

## 禁止

- 不静默翻转方向。
- 不把「一族白字、一族黑字」当成品。
- 不在深色端直接沿用浅色端的同一个填充 hex。
