# 光学对齐

> 适用：页面、组件、图标组与文字容器的光学对齐判断；用于评审、设计规格与图纸调整。
> 边界：几何对齐负责可重复，光学对齐负责看起来成立；不给通用像素，不替代真实渲染与人工确认。

## 1 三套基准

| 基准 | 取什么 | 适合 | 风险 |
|---|---|---|---|
| **几何边界** | 外框、包围盒、画板 | 可重复、可自动布局 | 与可见形状和视觉重量脱节 |
| **墨迹边界** | 非透明像素、字形墨迹、剪影 | logo、图标、文字 | 需要透明度或字形度量，不同字体不同 |
| **质量中心** | 模糊后的亮度 / 透明度质心 | 不规则形状 | 模糊半径、背景与颜色会改变结果 |

- 容器排布用几何；图形与文字看可见轮廓；不规则图形看质量中心。
- 三套基准不能混用：外框对齐不等于墨迹对齐，墨迹居中不等于视觉重量居中。

## 2 视觉重量

视觉重量由面积、对比、颜色、位置、孤立、形状复杂度与朝向、深度、内在兴趣、动势共同决定。界面里可观察的对应项：

- 面积与尺寸；
- 明度对比、彩度；
- 线宽、填充密度、线性 / 实心；
- 位置（上方、左侧、光学中心附近更重）；
- 孤立与留白；
- 文字密度、字号与字重；
- 图片、人脸、强方向性图形；
- 动效。

**重量不等于面积**：小面积高对比元素可以压过大面积低对比色块；实心图形通常比同尺寸线性图形重。

光学中心通常指视觉上略高于几何中心的点；它是构图经验，不是固定比例。

## 3 修正方法

### 3.1 图标组

- 同一组先统一线宽、填充密度与透视。
- 用 keyline（方 / 圆 / 横竖矩形）归一轮廓；圆形、尖角按视觉重量略大于方形。
- **等外框不等于等重量**：同一组图标允许尺寸不同，差值由 keyline 与视觉重量决定，不写通用百分比。
- 对称图形不偏移；播放键、箭头、勾选等不对称图形按视觉中心对齐，不按包围盒中心。
- 跨库混排要重新校验，不直接套另一套图标的尺寸。

### 3.2 不规则图形

- 先去掉透明边距，按墨迹边界对齐；素材自带留白不算设计间距。
- 需要重心时用质量中心；三角形、箭头、播放键按质心，不按包围盒。
- **模糊—质心是可选验证**：有工具或 AI 时可模糊到只剩质量块再比较质心；没有时用眯眼 / 缩小视图判断，不要求人工每次执行。
- 模糊半径按画面尺寸定，不作为设计值；不同图形不共用同一个像素偏移。

### 3.3 图标与文字

- 先看图标集的绘制基准：按基线设计的符号用基线，按字身框设计的图标用字面中线；同一组不混用。
- 行内控件对齐首行字面中线；多行标签只对齐第一行，不按整块文本垂直居中。
- 单行文字在固定高度容器里，行盒居中不等于字面居中；全大写、无下伸部的短标签容易视觉偏高，补偿量按字体度量登记，不写通用像素。

### 3.4 文字与圆角容器

- **文字轴**：以边框内侧 + 内衬为轴；并排卡片先对齐文字轴与基线，再对齐外框。
- 容器外的标题 / 说明与卡片对齐时，优先对齐内文字轴；只有无圆角或文字位于直边段时才对齐外框。
- **护角**：首行可见顶边落在弧高内（`y < r`）时，其左边缘至少距容器左边 `r − √(r² − (r − y)²)`；不想算时，让首行落到弧线以下，或左内衬 ≥ `r`。`r` 为圆角半径，`y` 取可见顶边到容器顶边的距离，不是行盒顶边。
- 圆形 / 非矩形内容按实际轮廓核对；图片按裁切或可见剪影处理。
- 修正优先用现有内衬档或下移内容，不新增零散值。

### 3.5 列表符号与图片

- 列表符号、开引号、破折号悬挂在文字轴外，正文轴线不动；不支持悬挂标点时，按字体侧边距登记偏移。
- 图片、插画先去透明边距，按可见剪影对齐；需要时按内容裁切，不把外框当可见边界。

### 3.6 常见场景

| 场景 | 对齐基准 | 做法 |
|---|---|---|
| 图标组 / 工具栏 | keyline | 方 / 圆 / 矩形 keyline；不对称图形按视觉中心 |
| 图标列 + 文字列 | 图标墨迹 / 文字轴 | 图标在固定列按墨迹居中；文字轴独立 |
| logo 墙 / 图形集合 | 墨迹边界 | 去透明边距；按墨迹中心与视觉重量 |
| 圆角卡片内文字 | 文字轴 | 边框内侧 + 内衬；首行按护角公式 |
| 卡片外标题 | 内文字轴 | 不对齐外框；无圆角或直边段例外 |
| 圆形头像 / 单字徽标 | 字面中心 | 横纵都按墨迹；圆形按视觉尺寸重新检查 |
| 列表符号 / 引号 | 文字轴 | 符号悬挂在文字轴外；正文不缩进 |
| 图片 / 插画 | 可见剪影 | 去透明边距；需要时按内容裁切 |
| 控件 + 标签 | 首行字面中线 | 多行只对齐第一行 |
| 标题 + 标签 / 徽标 | 基线 / 字面中线 | 不按盒中心硬凑 |

## 4 审计

| 层 | 输入 | 能回答 | 不能回答 |
|---|---|---|---|
| L0 几何 | 外框、墨迹边界、字体度量、半径与内衬 | 是否共用 keyline / 文字轴；护角公式是否满足 | 真实视觉重量、图片内容 |
| L1 渲染 | 最终截图、透明度、模糊质心 | 重量分布、质心偏移、前几个热点 | 语义、意图、可读性 |
| L2 人检 | 100% 尺寸、眯眼 / 模糊、灰度 | 看起来是否对齐、是否有偏重 | 可重复的数值 |

- 先查「声明的是盒子还是轮廓」与「文字轴是否一致」；墨迹级检查在最终尺寸做，不在放大视图里调。
- 报告质心偏移、墨迹边界、文字轴一致性、声明顺序与实测顺序的差异；不要合成单一总分。
- 模糊图与显著性图只作第二意见，不当阻断条件。

## 5 边界与反例

- 用统一像素偏移覆盖所有字形与图形。
- 用包围盒中心代替视觉中心。
- 把模糊—质心写成必检流程。
- 在设计工具放大视图里调对齐，回到 100% 尺寸后失效。
- 只验证一种字体、一种语言或一个平台就外推。
- 换字体、换语言、换平台后，重新验证字面高度、字面中线、数字宽度与行盒。
