# 动效与反馈规范

> 适用：时长 / 循环 / 延迟 / 曲线选择、角色编排、反馈设计、减少动效与平台降级。
> 评审步骤见 [`scenarios/review-motion.md`](../scenarios/review-motion.md)。

## 1 四条轴

动效不是装饰层，而是状态与因果的表达。设计语言只定义四条轴：

| 轴 | 回答 | 是否进入设计值 |
|---|---|---|
| **时长** | 一次过渡多久 | 是 |
| **循环** | 周期运动多快 | 是 |
| **延迟** | 编排偏移多少 | 是 |
| **曲线** | 加速 / 减速 / 匀速 | 是 |

角色、编排、反馈属于使用方式，不属于轴本身。手势跟手、速度交接、回弹属于组件运行时；静态设计只承诺可复现的曲线与时长。不引入弹簧参数作为系统设计值。

## 2 时长

**100ms 起步，100ms 步进，默认 6 档。**

| 档 | 值 | 60Hz 帧数 | 典型用途 |
|---|---|---|---|
| 1 | **100ms** | 6 帧 | 焦点 / 颜色 / 即时反馈 |
| 2 | **200ms** | 12 帧 | 小元素出现 / 轻量展开 |
| 3 | **300ms** | 18 帧 | 常规进入 / 面板 / 屏内移动 |
| 4 | **400ms** | 24 帧 | 大面板 / 页面区块 |
| 5 | **500ms** | 30 帧 | 页面级转场 |
| 6 | **600ms** | 36 帧 | 大区块 / 强调 |

1. **100ms 是可感知运动的下限**：60Hz 下 6 帧；50ms / 70ms 只有 3–4 帧，更像跳变，不再作为档位。
2. 常用三档是 **100 / 200 / 300**；400 以上只给大面板与页面转场。
3. 可以扩展到 700 / 800ms，但默认不背低频档。
4. **禁止字面量时长**：直接写 300ms 之类的数值一律不允许，必须引用时长档。
5. 缺档按 P15 处理：先找角色，再用已有档的整数倍并登记「哪一档 × 几」。

## 3 循环

**1s / 2s / 4s，独立于过渡时长。**

| 档 | 值 | 典型用途 |
|---|---|---|
| 1 | **1000ms** | spinner / 进度旋转 |
| 2 | **2000ms** | 骨架呼吸 / 闪烁 |
| 3 | **4000ms** | 环境动效 / 长时间呼吸 |

1. **循环不是更长的过渡**：不要用最大时长档乘倍数做 loading；两者语义不同。
2. 1s 是 spinner 的常见节奏；觉得快就用 2s / 4s，不改过渡梯子。
3. 装饰性无限循环不进系统；核心只允许明确的 loading / progress 与环境动效。
4. 可以扩展到 8s，但默认不背低频档。

## 4 延迟

**50ms 起步，×2，默认 3 档；400ms 只作可选扩展。**

| 档 | 值 | 60Hz 帧数 | 用途 |
|---|---|---|---|
| 1 | **50ms** | 3 帧 | stagger 步长 |
| 2 | **100ms** | 6 帧 | 小交接 |
| 3 | **200ms** | 12 帧 | 中交接 |
| 4（可选） | 400ms | 24 帧 | 非交互的一次性序列；默认不发布 |

1. **20ms / 40ms 不再作为档位**：60Hz 下只有 1.2 / 2.4 帧，单次延迟基本读不出来。
2. 延迟只服务编排，**不用于交互等待**；tooltip / hover intent 属于交互延迟，不在这套设计值里。
3. **进入 / 离开不带延迟**；只有序列 / 交接才用。
4. 400ms 只在非交互、一次性、可取消性不受影响的序列里登记使用；不进入默认。

## 5 曲线

只保留 3 条曲线 + 1 个固定常量，由一个参数 `t` 派生：

```text
standard   = cubic-bezier(t,     0, 1-t, 1)
decelerate = cubic-bezier(0,     0, 1-t, 1)
accelerate = cubic-bezier(t,     0, 1,   1)
linear     = cubic-bezier(0,     0, 1,   1)
```

默认 `t = 0.42`：

| 曲线 | 值 | 用途 |
|---|---|---|
| **standard** | `cubic-bezier(.42, 0, .58, 1)` | 屏内移动 / 展开收起 / 尺寸变化 |
| **decelerate** | `cubic-bezier(0, 0, .58, 1)` | 进入 |
| **accelerate** | `cubic-bezier(.42, 0, 1, 1)` | 离开 |
| **linear** | `linear` | 进度 / 加载 / 旋转 / 连续循环 |

性质：

- `accelerate = mirror(decelerate)`：时间反转，严格镜像；
- `standard` 自身对称，起点与终点斜率都为 0；
- 三条曲线都在 `y ∈ [0,1]` 内，单调、无过冲；
- `t = 0.42` 同时等于 Apple Core Animation 的 `easeInEaseOut` / `easeOut` / `easeIn` 与 CSS 的 `ease-in-out` / `ease-out` / `ease-in`。

规则：

1. **时长与曲线成对使用**：进入减速、离开加速、屏内标准；不混。
2. `linear` 只用于连续量；不用于进出场与状态切换。
3. **组件禁止直接写 `cubic-bezier(...)`**，只能引用曲线设计值。
4. **系统曲线无过冲**：它会同时用于颜色和透明度；回弹 / 过冲是组件层的空间扩展，低频使用。
5. `t` 只控制入场 / 离场平衡：`t` 越大入场越干脆、离场越晚；`t` 越小入场越柔和、离场越早。

**曲线选择顺序**：先看元素是屏内移动 / 进入 / 离开 / 连续量，再选标准 / 减速 / 加速 / 匀速。自定义曲线不是风格选项：必须说明它解决的空间 / 时间问题，并在真实场景验证；不无理由写 `cubic-bezier(...)`。

## 6 起手角色

角色属于使用层；只做指向，不产生新值。

| 角色 | 时长 / 循环 | 曲线 | 偏移 | 典型场景 |
|---|---|---|---|---|
| `enter` | 时长 3 | 减速 | — | 页面 / 弹层 / 卡片进入 |
| `exit` | 时长 2 | 加速 | — | 同上，反向离开 |
| `move` | 时长 3 | 标准 | — | 屏内展开 / 折叠 / 位置与尺寸 |
| `press` | 时长 1 | 减速 | — | 按压反馈 |
| `indicator` | 时长 2 | 减速 | — | 勾 / 点 / 滑块 / 指示条 |
| `color` | 时长 1 | 标准 | — | 边框 / 底色 / 文字 |
| `focus` | 时长 1 | 减速 | — | 焦点环 |
| `emphasis` | 时长 4 | 标准 | — | 低频强调 / 首次引导 |
| `loading` | 循环 1 | 匀速 | — | spinner / 进度旋转 |
| `skeleton` | 循环 2 | 匀速 | — | 骨架呼吸 |
| `ambient` | 循环 3 | 匀速 | — | 环境动效 |
| `stagger` | — | — | 延迟 1 | 序列步长 |
| `handoff` | — | — | 延迟 2 / 3 | 交接 |

上表的数字是档号，不是毫秒；具体值查 §2–§4。

1. **只允许一跳**：角色只能指向设计值，不能指向另一个角色。
2. **不写字面值**：`300ms` / `cubic-bezier(...)` 一律非法。
3. **进入慢于离开**；进入减速、离开加速。
4. **匀速只给 loading / skeleton / ambient**。
5. **press / color / focus / indicator 不带延迟**。
6. 角色不是配置项：配置工具改轴与曲线，不改角色名；风格层换 `t` 或显式曲线。

## 7 编排

### 7.1 即时响应

- 用户输入必须立即有反馈；按下、输入、焦点启动不带延迟。
- 延迟只用编排；tooltip / hover intent 属于交互延迟，不进这套设计值。
- 不要让用户等动画完成才能操作；可取消的流程不加长延迟。

### 7.2 优先重叠，不等待

- 延迟是从触发时刻算起的偏移，不是等上一个动画播完。
- 能用时长差 / 曲线差做出的层次，不用延迟：A、B 同时开始，B 用更长时长或更软曲线停稳。
- 序列总预算按 `max(延迟 + 时长)` 算，不是单个元素时长；入场最后一项 ≤ **500ms**。

### 7.3 stagger

- `stagger = 50ms × index`；只编排首屏可见项。
- 50ms 步长 + 200ms 时长：最多 7 项（300 + 200 = 500）。
- 50ms 步长 + 100ms 时长：最多 9 项（400 + 100 = 500）。
- **退出序列不 stagger**；退出要快、要同步。
- 频繁刷新 / 高频交互不做 stagger；只用于首次加载、偶发揭示。

### 7.4 顺序与空间

- 多元素进场按「稳定 → 动态 → 主行动 → 装饰」：骨架 / 外壳 → 正文 → 列表 / 结果 → 主按钮 → 装饰。
- **离开但仍在附近**（侧栏收起、面板折叠）用 `move`（标准），不用 `exit`（加速）。
- 动效方向顺着手势；逆着手势的位移会破坏空间连续。

### 7.5 可打断

- **状态驱动用过渡**：开合 / 状态切换优先用过渡，它能在中途反向；关键帧中途反向会跳变，只用于一次性序列。
- **从当前值开始**：动画进行中再次触发时，从当前呈现值开始，不排队、不跳回起点；关闭中的浮层被再次打开，应跟手反向，而不是等关闭播完。
- **不锁输入**：过渡期间可点击、可聚焦、可取消；不把焦点、事件或最终状态绑在动画结束回调上。
- **核对**：快速开关、中途取消、元素移除、最终状态、滚动位置、焦点返回。

### 7.6 动画属性与成本

- 位移与显隐优先走合成（位移变换 / 透明度）；颜色、描边颜色和焦点颜色按已有颜色 / 焦点角色表达。
- 禁止对会触发布局的属性做过渡（尺寸、位置、内外边距、间距、字号与行高）。
- 高度展开用裁切 / 缩放 / 容器测量后设高度均可，但必须由组件层封装，不写进静态稿。
- 位移变换不是无条件的性能保证；模糊、阴影、覆盖面积、层数和逐帧重绘按实际场景评估。
- 禁止对全部属性做过渡，或没写明属性。

### 7.7 循环与边界

- 系统只允许两类循环：明确的 loading / progress，以及 4s 档驱动的环境动效。
- 边界用软过渡：减速 / 标准，不要硬停。
- 默认不过冲；回弹是低频、组件层的空间扩展，不用于颜色 / 透明度。

### 7.8 来去路径

- 同一元素进出走同一路径、反向播放；不要进入从左、离开从右。
- 起点在触发物，终点在内容；展开从触发点开始，收起回同一位置。
- 屏内移动用标准；进入减速；离开加速；离开通常更短，因为用户已经知道结果。
- 有空间关系的元素用位移 / 缩放 / 共享元素；没有空间关系时才用淡入淡出，不要用 crossfade 掩盖错误的父子关系。
- 不要让动效暗示错误的层级：从底部进入的 sheet 应回到底部；从列表项展开的详情应收回该项。

### 7.9 常用动效模式

| 模式 | 来去路径 | 建议角色 | 注意 |
|---|---|---|---|
| 弹窗 / sheet | 从触发点或屏幕边缘进入，关闭回同一边 | enter / exit | 焦点返回触发点；不阻塞输入 |
| 页面 push / pop | 新页从右侧或前景进入，返回反向 | move / enter / exit | 保持滚动位置与焦点 |
| 折叠 / 展开 | 从标题或触发点展开，收起回同一点 | move | 可打断；内容高度用裁剪 / 缩放 / 测量 |
| 列表项展开 | 从行位置展开，收起回行 | move | 不要改变行高几何 |
| Toast / snackbar | 从底部或顶部进入，自动消失 | enter / exit | 不阻塞操作；减少动效下静态 |
| 加载 | 循环，不占布局 | loading / skeleton | 停止后保留静态线索 |
| 按压 | 覆盖层反馈 | press | 不改外框几何 |
| hover / focus | 颜色或焦点环淡入 | color / focus | hover 只在有指针设备 |

## 8 反馈

反馈只回答三个问题：

| 角色 | 回答什么 | 载体 | 用在哪 |
|---|---|---|---|
| **press** | 按到了吗 | 覆盖层 | button / nav / tabbar / radio-group / details summary |
| **state** | 状态变了吗 | 颜色层 / 框内指示物 | nav 圆角色块、tabbar 变色、checkbox 勾、radio 点、switch 滑块、details 箭头、range thumb、表单错误提示 |
| **focus** | 键盘在哪 | 焦点环淡入 | 所有可聚焦组件与表单壳 |

1. **块面**（命中区 ≥ 控件高度）→ press；**点 / 线**（勾、点、滑块、thumb）→ state；**选中**：nav 用圆角色块、tabbar 只用文字 / 图标变色；**文本** → 不加覆盖层。
2. 同一次交互最多两层（press + state），超过就是噪音。
3. press 的前置条件（相对定位、裁切、伪元素）由 press 自己承担；宿主不满足时用包裹层。
4. 时长按面积取角色：点 / 线 `indicator`（时长 2），控件 / 块面 `press`（时长 1），大面 `move`（时长 3），纯颜色 `color`（时长 1）。
5. 焦点环 100ms 淡入；能放到外壳就放外壳。
6. **状态反馈不引起重排**：不用宽高、内外边距、定位偏移、边框宽度表达状态；小幅、不触发重排的位移 / 缩放 / 旋转可用，但需满足热区、越界、清晰度与减少动效的约束。
7. **骨架与可见边界**：可见边界（描边 / 底色 / 阴影）可以去，骨架（内衬 / 最小尺寸 / 圆角 / 最小命中区）不能；无边框变体只改可见边界，不把内衬 / 最小高度归零。

反馈信息与生命周期：

| 反馈 | 必须区分的信息 | 责任边界 |
|---|---|---|
| 状态 | 按下、选中、当前、展开和焦点不是同一件事 | 语义与视觉映射由组件约定与交互态定义（见 `states.md`） |
| 加载 | 正在处理、内容将出现、真实进度 | spinner / 骨架 / 进度条按场景选；停掉动画后保留可识别的静态线索和适用语义 |
| 结果 | 成功 / 失败、下一步或撤销入口 | 应用决定消息及恢复流程；适用时用 status / alert，不把所有结果都做成打断播报 |
| 错误 | 哪里错、如何修复、如何到达字段 | 行内关联、摘要和焦点路径属于组件 / 页面行为，不是只换红色或播放动画 |

- 自动消失的信息若形成阅读或操作的时间限制，按 WCAG 2.2.1 及例外核对；自动开始、长期并呈的运动或自动更新按 2.2.2 判断；闪烁另按 2.3.1 检查。
- 过渡插值、关键帧动画和脚本控制有不同的取消 / 反向能力，均不自动负责挂载、卸载、焦点和事件清理；顶层和 display 的生命周期不能用时长设计值单独解决。

## 9 降级与平台

| 端 | 做法 |
|---|---|
| **H5 / Web** | CSS 过渡 / 关键帧；手势驱动或需要中途打断时用 WAAPI |
| **小程序** | WXSS 过渡 / 动画；按压缩影用平台能力；无 WAAPI |
| **减少动效** | Web 用减少动效偏好；小程序用系统信息 / 用户设置，取不到时按「不播放编排」处理 |

**减少动效必须兜底：**

- 时长 → 近乎为零，延迟 → 零；不是只清时长，序列也不等待。
- **循环不归零**：近乎为零的时长 + 无限循环会疯狂迭代；循环必须由组件显式停止，或包在「允许动效」的判断里。
- 编排层跳过 stagger / 序列：所有元素同时出现，而不是等一串 0ms 的延迟。
- 减少动效不等于去掉状态：按下态、选中态、焦点态仍然可见，只是瞬时切换。
- 非必要动效包在「允许动效」的媒体查询内；清零是兜底，不是唯一手段。
- 停止 spinner / 骨架后，静态图形、文案与语义仍需说明正在处理；焦点和最终状态不能依赖动画结束回调才成立。

## 10 评审口径

**可检查项**：时长 / 循环 / 延迟 / 曲线来自设计值；无字面量时长、无直接写的贝塞尔曲线；不对布局属性做过渡、不对全部属性做过渡；状态反馈不引起重排；关键帧 / 无限循环有减少动效兜底。

**必须人检**：实际时序、快速开关、中途取消、焦点返回；入场预算、退出 stagger、曲线观感。

数值可复算不等于人因阈值；检查通过不等于真实体验合格。
