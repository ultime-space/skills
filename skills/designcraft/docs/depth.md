# 表面与光影规范

> 适用：面（层级 / 填充 / 形态）、半透明、分块策略、遮罩、未知底、材质；两套光系统、五个光槽、投影、环境遮蔽、边界与层级。
> 评审步骤见 [`scenarios/review-depth.md`](../scenarios/review-depth.md)。

## 1 面 = 层级 + 填充 + 形态

一个面由三件事决定：**在第几层、填什么、有没有厚度**。三者正交。

**层级**：面在画布内部叠加的次序。

| 面阶 | 说明 |
|---|---|
| **画布** | 页面底、局部模式块的根，**一级面容器，通常不透明；半透明需验证最坏背景** |
| **抬升面** | 卡片 / 面板 / 输入框底，二级面容器，可半透明；需有已知底或验证合成对比度 |
| **浮层面** | 浮层 / 弹层 / 抽屉，二级面容器，可半透明；主要内容建议实色或近实色 |
| **凹陷面** | 凹陷区，二级面容器，可半透明；需有已知底 |

**形态**：决定有没有受光面，与层级无关。

| 形态 | 侧壁 | 允许的表现 |
|---|---|---|
| **平面** | 无 | 只有轮廓与面差；**不允许**高光 / 明暗 |
| **凸起** | 有，外凸 | 受光边亮、背光边暗 |
| **凹陷** | 有，内凹 | 受光边暗、背光边亮 |

- **平面无高光**：高光来自侧壁对光的反射；没有厚度就没有受光面。无厚度的轮廓只能用描边，不能用高光假装。
- 层级与形态正交：抬升面可以是平面（纯色块），画布也可以是凹陷区。
- 形态是**组件级**声明：同一主题下不同组件形态不同；同一组件在同一风格内不得切换形态，状态也不行。
- **凹凸感由光影画，不由底色画**：凹陷面只表示「比画布暗」，不等于是凹陷形态。

**一级面容器是可读性风险区，不是强制实色**：

- 一级面容器 = 直接落在未知 / 复杂背景上的第一个面，或承载正文 / 表单 / 主要操作的容器。
- 半透明可以用；判断标准是**合成后的有效对比度**，不是面本身是否透明。
- 底不可控时：局部实色底衬、提高不透明度、加遮罩，或改为不透明面；至少给最坏背景留回退。
- **输入框 / 表单 / 浮层正文**：可读性优先，建议不透明或接近不透明的底。
- **玻璃 / 材质风格**：可以半透明；不强制白底，但正文 / 主表单要保证可读性。

**方向规则**：抬升一律变亮、下沉一律变暗，不随模式翻转。

- **画布反解**：两端画布到各自极点取同一对比度，对称比 **1.20**（可行带 **1.15–1.26**）；上端取 1.14 关于 1.20 的镜像 1.26。
- **面阶目标**：抬升 **1.10** / 浮层 **1.14** / 凹陷 **1.07**；具体值以项目当前取值为准。
- 抬升若用黑 tint，会与黑色阴影互相抵消，层级反而读不出来。

**tint 可以带偏色**：允许偏冷、偏暖或带一点主题色，但不改「抬升变亮、下沉变暗」的方向。

**不透明抬升面用组合**：需要实色抬升面时，壳先落画布，再叠抬升面；不另发第二套实色值。

**用整元素透明度不是面阶**：它同时改变文字、图标与子内容，合成后既不是目标面色、也无法按面阶承诺反解。

**模式是可嵌套的作用域**：局部模式块的根必须是不透明面；媒体内容先铺遮罩，再按容器模式取色。

**中性族不参与模式**：遮罩 / 阴影 / 环境遮蔽的取值、极性与偏色范围见 [`color.md`](./color.md) §3。

## 2 半透明有五类用途

| 载体 | 用途 | 承诺 |
|---|---|---|
| **面阶 tint** | 抬升 / 下沉的面阶 | 对已知中性画布按目标反解 |
| **墨块** | 区域内分块、占位 | 叠在任意底上压暗 / 提亮，不承诺最终对比 |
| **状态层** | hover / pressed / selected / disabled | 只在已知底色上可辨 |
| **遮罩** | 分离背景与前景 | 削弱干扰，不保证动态背景上的文字对比 |
| **阴影墨量** | 投影 | 只服务投影，不是通用透明度档 |

**分工**：层级差用面阶 tint，块内分区用墨块，交互反馈用状态层，浮层背景用遮罩，投影用阴影墨量。不要用一套替代另一套。

**常见误用**：用填充表达抬升 / 下沉；用整元素透明度表达面阶；把遮罩当万能半透明底；把阴影 alpha 当通用透明度档。

## 3 分块、遮罩与材质

### 3.1 分块手段三档

| 档 | 分块手段 | 阴影 | 分隔线 |
|---|---|---|---|
| **tonal**（默认） | 底色阶 | 不用 | 少用 |
| **outline** | 1px 描边 | 不用 | 用 |
| **elevated** | 投影 | 用 | 不用 |

> 这三档是把「面 × 边界 × 光影」打包好的**预设**，不是三个维度。需要更细的组合时按各自的轴组合。

三条约束：

1. 与颜色、圆角正交。
2. 只影响分块、不动排版。
3. 深底需复验：`elevated` 在深底最弱；深色投影不足以辨识时，用面差或边界补足。

**同一层级只允许一种抬升方式**：卡片是底色阶，纸内就用井，不能再叠第二张浮起的卡片。骨架屏不参与本维度。

### 3.2 遮罩：全区域半透明背景色

遮罩的作用是把背景压暗到前景可读，或聚焦 / 阻断，不是「让页面变灰」，也不表达高度。它是半透明背景色，**不属光影**。

**默认**：单一黑色、单值、不随模式。环境偏色默认省略，设置后与阴影 / 环境遮蔽共用同一枚墨。

**遮罩与环境遮蔽是两层**：遮罩全区域；环境遮蔽在元素边缘。抽屉 / 对话框 / sheet 的色块本体是容器，不是背景。

### 3.3 未知底

现行规范只覆盖登记的中性面。**图片、渐变、视频、多层半透明叠加都不在承诺范围内。**

三选一：局部不透明底衬；改用不透明面；经验证的遮罩。

**不要用提高全局 alpha 代替验证**：那样既解决不了动态背景，又把已知面推离原目标。

### 3.4 材质：填充的一套实现

材质不做可复算的档位。它是**填充的一种实现**，不是叠在填充上的第二层：启用材质 = 整套填充被替换（底色、透明度、背景模糊一起换），不允许「普通面的色 + 额外的模糊」这种双来源。

**当前只承诺一个封闭角色：玻璃**。集合是封闭的，新增材质单独评审；金属、背景图、边框图不承诺。

玻璃的三条要求：

1. 覆盖率对**声明的参考底**反解，不对「最坏底」反解——单一透明度填充在最接近自身颜色的底上增量恒为 0。
2. 背景模糊复用投影的模糊尺度，不另立一套。
3. 不支持背景模糊时整套退化（半透明 + 发丝线 + 高光），退化的是整组，不是单个属性。

**玻璃不承诺在任意底上可辨**：需要保证轮廓时，用描边补边界、或用环境高光补可见度。

## 4 两套光系统与五个光槽

**全局光有方向，环境光无方向**。这是两个系统，不是一盏灯的两半。

| 光槽 | 形态 | 跟方位角 |
|---|---|---|
| 全局光 · 高光 | 内层亮边 | 是 |
| 环境光 · 高光 | 内层亮环（全环） | 否 |
| 全局光 · 投影 | 外层投影，四档 | 是 |
| 全局光 · 暗侧 | 内层暗边 | 是 |
| 环境光 · 遮蔽 | 外层，无偏移，四档 | 否 |

- **两个高光槽都在内侧**：高光是凸面表面的内容，画在面内，不占外缘。
- **受光边由方位角推出**：每条边的权重是「边法线与光线方向的夹角余弦」，正值出亮、负值出暗、零只剩环境项。不提供手选的「哪几条边亮」。
- **方向边线必须有环境底**：分边项在圆角处衰减到 0，受光边与背光边之间会出现断点；环境高光是连续的一圈，负责填住它。启用方向高光或暗侧时，环境底必须非零且可辨。
- **光色只有两个输入**：主光色决定全局光高光，环境色决定环境高光与全部阴影墨；不允许逐槽调色。
- **形态前提**：平面没有受光面，平面形态下高光与明暗必须为 0。
- **叠加天然封顶**：多层高光 / 多层墨按 alpha 合成，上限是纯白 / 墨色，不需要额外预算；档位只描述单槽，不描述合成。

**填充余量是条件约束**：只有在「有厚度 + 启用高光」时，才要求面离纯白足够远；扁平或只用投影时不要求。

## 5 投影：四档与三层

投影同时需要两件事：物体与底面的**接触暗线**，以及向外的**柔和衰减**。单一模糊做不出「贴边很实、远处很柔」，所以拆成三层。

| 层 | 作用 | 几何 |
|---|---|---|
| `contact` | 接触暗线 | offset 1px、blur 2px |
| `inner` | 近边半影 | offset = 上一档 halo / 4，blur = 上一档 halo |
| `outer` | 远场衰减 | offset = 当前档 halo / 4，blur = 当前档 halo |

**几何**：`halo_n = 8 × 2^(n−1)` → **8 / 16 / 32 / 64**；`offset = halo / 4`。四档由端点推出：`log2(64 / 8) + 1 = 4`。

**墨量**：`u = 4%`；`total = (n+1)u` → **8% / 12% / 16% / 20%**；`inner = contact = u`；`outer = max(1, n−1)u`。

| 档 | contact | inner | outer | 总墨 | 角色 |
|---|---|---|---|---|---|
| 1 | `1/2 · 4%` | 空层 | `2/8 · 4%` | 8% | control |
| 2 | `1/2 · 4%` | `2/8 · 4%` | `4/16 · 4%` | 12% | raised |
| 3 | `1/2 · 4%` | `4/16 · 4%` | `8/32 · 8%` | 16% | overlay |
| 4 | `1/2 · 4%` | `8/32 · 4%` | `16/64 · 12%` | 20% | deep |

表中 `1/2` 写作「offset / blur」，单位 px。

- 四档由模糊端点倍增推出；公开设计值是预组合后的四档，三层是内部配方。
- 锚点：`contact` 每档都有；第 1 档没有 `inner`（空层，不是缺结构）；第 4 档三层全开。
- 多层叠加的合成 alpha 按 `1 − Π(1 − aᵢ)` 计算；表中墨量相加只是配方标度。
- 场景常用 1–3 档；4 保留给大面积场景表面。

**其余四槽各只有一层**：两个高光槽是 1px 内边 / 内环，暗侧是 1px 内边，环境遮蔽是单层无偏移模糊。它们没有「接触线 + 远场」的分工，拆三层只增加绘制层数。

**单墨**：全项目一枚阴影墨，跟中性中段色相，保证墨暗于两端画布。环境偏色可覆写色相 / 彩度，上限很低。各层共用同一枚墨，不按层分色。

**深浅共用同一套墨与 alpha**，深色不做强度补偿。代价是深色下投影可能几乎不可见，这是黑底叠黑的物理上限。

## 6 框架、浮层与环境遮蔽

| 层 | 例子 | 主要分隔 |
|---|---|---|
| **框架** | navbar、tabbar、sidebar | 描边 / 面阶 / 环境高光；可选环境遮蔽；不用投影 |
| **浮层背景** | dialog / sheet / drawer 的遮罩 | 遮罩，不属光影 |
| **浮层容器** | dialog / sheet / drawer 的色块本体 | 环境遮蔽 + 环境高光 / 材质；不用投影 |

**环境遮蔽**：居中、四边、无方向；只用纵深改变强度与范围；与投影共用同一枚墨。它可以只压单边，用于贴边框架。

- 框架贴边优先用描边 / 面阶；环境遮蔽只是「很浅的浮层感」。
- 浮层容器用环境遮蔽 + 环境高光；方向影被自己挡住，这是物理正确的。
- **外投影与环境遮蔽互不强制**：浮起的卡片可以只有投影，贴边的框架可以只有遮蔽。

**为什么不用投影**：底部 sheet 的方向影落到屏幕外或被自己挡住；抽屉的向下影不能把抽屉和内容横向分开；四边遮蔽才是有效的分隔信号。

**角色落点**：`flat` = 无；`control` = 投影 1；`raised` = 投影 2；`overlay` = 投影 3；`modal` = 遮罩 + 环境遮蔽。

## 7 边界与光槽可以共存

**边界只有两种**：描边（占布局的线）与焦点环（不占布局）。背景色阶与投影可以制造分块感，但它们不是边界。

边界与任一光槽可以同时存在；同一条边上「描边 + 亮线」会形成双线，属风格建议，不是硬约束。

**光槽不是边界**：环境高光可以让轮廓更容易看见，但它属于光影，不承担边界语义；强制颜色下会被移除，所以不能作为唯一的轮廓信号。

## 8 深度与堆叠

- **视觉深度**：面差、投影、两个高光槽、环境遮蔽表达的「离底面多远」。
- **堆叠顺序**：层叠上下文内的前后关系，由堆叠层级与顶层决定。

堆叠层级不成为设计值：绝对值不承载设计承诺。使用方维护本地顺序，但保持同一套相对关系：`base < sticky < nav < mask < popup < toast`。

**混合场景**：常驻顶栏、浮层与角标共用同一套相对顺序；`dialog` / `popover` 进 top layer，脱离普通层叠竞争；角标跟随宿主，不单独争夺层级；关闭浮层后焦点回到触发点，背景用 `inert`。具体层叠上下文由产物本地实现，不新增设计值。

**深度的信号必须一致**：面差、投影、高光不能互相打架（例如「更亮的卡片反而投更重的影」）。物理讲不通就不做。

## 9 按下与深浅

**按压不改变外框**：状态反馈不改变元件外框的位置与尺寸；位移、缩放、宽高、内距都不用于表达按压。

- **轻拟物**：只走覆盖层（叠墨，必要时降一档投影），形态不变——这是默认做法。
- **重拟物**：形态可以变，但必须由深度档派生（不下陷 / 浅陷 / 齐平 / 深陷），不手写「按下后的阴影值」。齐平时高光与投影都消失，深陷时极性反转。

**浅色靠描边 / 投影 / 面阶，深色靠两个高光槽 + 面差**，这是现行取舍，不是唯一答案。

- 投影只承诺方向与几何，不承诺深色可见度。
- 浅色接近纯白的面上高光不可见属物理规律，不做补偿。

**成本来源**：模糊半径 × 覆盖面积 × 层数。三层投影在超大模糊下面成本最高；环境遮蔽是单层。

- **不要对投影做过渡**：层级变化瞬时切换即可。
- **强制颜色**：投影被移除——框架 / 浮层必须保留描边 / 遮罩 / 环境高光兜底。
- **打印**：浏览器默认不打印背景色与投影；框架的描边是更稳的分隔。

## 10 评审口径

**可检查项**：一级面容器是否按最坏背景验证合成对比度；底不可控时是否有底衬 / 遮罩 / 回退；平面的元素是否误用了高光；方向高光是否配了非零环境底；光色是否只有主光 / 环境两个来源；框架 / 浮层是否误用方向投影；投影是否只用于离开底面的元素；环境遮蔽是否只用于贴近底面的元素。

**项目自检**：墨块 / 遮罩的实际取值；材质的参考底与回退。

**必须人检**：半透明面叠在图片 / 视频 / 多层上的表现；遮罩在深色 / 自定义画布上的压暗；强制颜色 / 高对比 / 减少透明下的层级；场景方向一致性；环境遮蔽四边是否均匀；大模糊 + 多层的性能；去掉投影后层级是否成立。
