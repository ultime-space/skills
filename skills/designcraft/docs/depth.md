# 表面与光影规范

> 源：设计规范 §7–§8（快照 2026-11-05）。本文件是面向 AI 的提炼，不是规范真源。
> 适用：面阶、半透明、分块策略、遮罩、未知底、材质边界；方向光、阴影、环境遮蔽、边缘高光、明暗与层级。
> 评审步骤见 [`scenarios/review-depth.md`](../scenarios/review-depth.md)。

## 1 面阶：一级面容器 + 半透明 tint

表面不是一组固定灰值，而是「一级面容器 + 叠在其上的 tint」。一级面可以透明，但要按最坏背景验证合成对比度。

| 面阶 | 说明 |
|---|---|
| **画布** | 页面底、局部模式块的根，**一级面容器，通常不透明；半透明需验证最坏背景** |
| **抬升面** | 卡片 / 面板 / 输入框底，二级面容器，可半透明；需有已知底或验证合成对比度 |
| **浮层面** | 浮层 / 弹层 / 抽屉，二级面容器，可半透明；主要内容建议实色或近实色，半透明需验证 |
| **凹陷面** | 凹陷区，二级面容器，可半透明；需有已知底 |

**一级面容器是可读性风险区，不是强制实色**：

- 一级面容器 = 直接落在未知 / 复杂背景上的第一个面，或承载正文 / 表单 / 主要操作的容器。包括：画布、输入控件底、弹层 / 抽屉 / 对话框的内容容器、直接放在图片 / 渐变上的卡片 / 面板。
- 半透明可以用；判断标准是**合成后的有效对比度**，不是面本身是否透明。底已知且合成对比度达标，就可以保留透明。
- 底不可控时，按风险处理：局部实色底衬、提高不透明度、加遮罩，或改为不透明面；至少给最坏背景留回退。
- **输入框 / 表单 / 浮层正文**：可读性优先，建议不透明或接近不透明的底；如果坚持半透明，必须验证最坏背景下的对比度，并提供减少透明 / 强制颜色 / 不支持模糊时的回退。
- **玻璃 / 材质风格**：可以半透明；不强制白底或实色底，但正文 / 主表单要保证可读性。风格层决定透明度，规范只报告风险，不阻断。

**方向规则（P10）**：抬升一律变亮、下沉一律变暗，不随模式翻转。

- 抬升面朝更亮表达，凹陷面朝更暗表达。
- **画布反解**：画布对称比 **1.20**（可行带 **1.15–1.25**），两端画布到各自极点取同一对比度；下界由浮层目标 1.14 决定，上界取下界关于默认值的镜像。
- **面阶目标**：抬升 1.10 / 浮层 1.14 / 凹陷 1.07；具体值以项目当前取值为准。
- 具体 tint 颜色与 alpha 由全局选择派生，不是通用常量；抬升若用黑 tint，会与黑色阴影互相抵消。

**tint 可以带偏色**：抬升 / 下沉的 tint 允许偏冷、偏暖或带一点主题色，但仍是 tint，不改「抬升变亮、下沉变暗」的方向；偏色的合法范围归 [`color.md`](./color.md)。

**不透明抬升面用组合**：需要实色抬升面（静态稿 / 图片容器）时，壳先落画布，再叠抬升面；不另发第二套实色值。

**用整元素透明度不是面阶**：它同时改变文字、图标与子内容，合成后既不是目标面色、也无法按面阶承诺反解；半透明只出现在面本身。

**模式是可嵌套的作用域**：完整机制见 [`foundations.md`](./foundations.md) §2.4。局部模式块的根必须是不透明面；媒体内容先铺遮罩，再按容器模式取色。

**中性族不参与模式**：遮罩 / 阴影 / 环境遮蔽的取值、极性与偏色范围见 [`color.md`](./color.md) §3；本节只消费，不另立第二套值。

## 2 半透明有五类用途

| 载体 | 用途 | 承诺 |
|---|---|---|
| **面阶 tint** | 抬升 / 下沉的面阶 | 对已知中性画布按目标反解 |
| **墨块（弱 / 中 / 强）** | 区域内分块、占位 | 叠在任意底上压暗 / 提亮，不承诺最终对比 |
| **状态层** | hover / pressed / selected / disabled | 只在已知底色上可辨 |
| **遮罩** | 分离背景与前景 | 削弱干扰，不保证动态背景上的文字对比 |
| **阴影墨量** | 阴影 | 只服务投影，不是通用透明度档 |

**分工**：层级差用面阶 tint，块内分区用墨块，交互反馈用状态层，浮层背景用遮罩，投影用阴影墨量。不要用一套替代另一套。

**一级面容器是风险区**：半透明可用，但要验证合成对比度；承载正文 / 表单 / 主要操作时，优先不透明或近不透明，底不可控时给底衬 / 遮罩 / 回退。

**现行字面默认**：墨块弱 / 中 / 强在浅色为黑 4% / 8% / 12%，深色为黑 22% / 35% / 45%；遮罩见 §3。这些是固定字面值，**不是任意画布 / 媒体背景下的可读性保证**。

**常见误用**：用填充表达抬升 / 下沉；用整元素透明度表达面阶；把遮罩当万能半透明底；把阴影 alpha 当通用透明度档。

## 3 分块与遮罩

### 3.1 分块手段三档

| 档 | 分块手段 | 阴影 | 分隔线 |
|---|---|---|---|
| **tonal**（默认） | 底色阶 | 不用 | 少用 |
| **outline** | 1px 描边 | 不用 | 用 |
| **elevated** | 投影 | 用 | 不用 |

三条约束：

1. 与颜色、圆角正交：同一份配色可配任一策略。
2. 只影响分块、不动排版：字号 / 字重 / 行高 / 字距 / 间距一档都不动。
3. 深底需复验：`elevated` 在深底最弱；深色投影不足以辨识时，用面差或边界补足。

**同一层级只允许一种抬升方式**：卡片是底色阶，纸内就用井，不能再叠第二张浮起的卡片。骨架屏不参与本维度，靠色块质量表达「正在加载」。

### 3.2 遮罩：全区域半透明背景色

遮罩的作用是把背景压暗到前景可读，或聚焦 / 阻断，不是「让页面变灰」，也不表达高度。它是半透明背景色，**不属光影**。

| 做法 | 条件 | 失效场景 |
|---|---|---|
| 固定黑 alpha | 浅色主题、背景可控 | 深色主题压不暗；叠在图片上不可控 |
| 专用 dim 色阶 | 有独立色阶可维护 | 需要多一组值 |
| 模糊 + 低 alpha | 平台合成器支持 | 成本高；无内容可透时退化为灰块 |

**默认**：遮罩为单一黑色 42%，单值、不随模式。环境偏色默认省略，设置后遮罩与阴影 / 环境遮蔽共用同一枚墨（彩度 ≤ 0.02）。

**遮罩与环境遮蔽是两层**：遮罩是全区域半透明背景色；环境遮蔽是元素边缘的环境光遮蔽。抽屉 / 对话框 / sheet 的色块本体是容器，不是背景：容器用环境遮蔽 + 边缘高光 / 材质，背景用遮罩。

### 3.3 未知底

现行规范只覆盖登记的中性面（画布、控件底、浮层合成面、凹陷面）。**图片、渐变、视频、多层半透明叠加都不在承诺范围内。**

三选一：

- **局部不透明底衬**：文字压在自己的实色块上，最稳；
- **改用不透明面**：用画布或实色抬升面，牺牲透明度换可计算性；
- **经验证的遮罩**：必须按实际内容验证，不能只凭 alpha 推定。

**输入框 / 表单同样适用**：如果直接放在图片 / 渐变 / 复杂背景上，优先给不透明或近不透明的父容器 / 自身底；如果坚持半透明，按最坏背景验证对比度，并给底衬 / 遮罩 / 回退。

**不要用提高全局 alpha 代替验证**：那样既解决不了动态背景，又把已知面推离原目标。

### 3.4 材质边界

材质（玻璃 / 金属 / 软面 / 磨砂…）**不做可复算的系统档位**。理由是可复算性：它是开放集合，档位无法由约束推导；模糊半径是观测量，没有守恒关系；一旦做成系统档位，就会用封闭结构承诺开放集合。它属于风格 / 材质层的设计知识，具体配方在 [`style.md`](./style.md)。

设计上只给两条注意事项：

1. **半透明面仍要过对比度评审**：玻璃盖正文时，优先给底衬或提高墨量；按最坏背景报告，不阻断。一级面容器不强制实色。
2. **低对比材质建议优先用于装饰**：新拟态一类用于正文 / 主表单时，额外确认文本可读性；风格层只给警告，不新增强制门槛。

材质的具体实现与降级由项目决定；本 skill 不提供材质配方。

## 4 方向光与阴影

### 4.1 光照模型

| 轴 | 取值 | 决定 |
|---|---|---|
| **光源方位** | 全局预设 `0° / 45° / 315°`（0° 正上，顺时针） | 影与高光在平面内的方向 |
| **光源仰角** | 30°–75°，默认 60°（仅烘焙） | 影长；不进入运行时 |
| **物体高度** | 1–4 档 | 模糊与墨量 |

- **光源在无穷远**：只有方向，没有位置。全页一个方向，滚动不重算；点光源 / 面光源会让影方向随元素位置变化，需要实时渲染，不进系统。
- **全局预设**：一个主题只选一个角度；组件继承，不提供按组件切换四向的能力。
- **高光不是第二光源**：它是同一光源的镜面项，方向由方位角推出，不允许单独再配一个边缘高光角度。
- **材质不在光照账里**：材质是开放集合，没有可复算的守恒量。

### 4.2 阴影：质感 × 方向

质感（模糊 / alpha / 墨 / 槽位）与方向在烘焙时组合，公开设计值是预组合后的四档阴影。

**三槽位**：`contact`（贴边，固定 `1/2 · 4%`）+ `inner`（过渡，上一档 halo，`4%`）+ `outer`（环境，当前 halo，承担剩余墨量）。

**几何**：`halo_n = 8 × 2^(n−1)` → `8 / 16 / 32 / 64`；`offset = halo / 4`；contact 固定 `1/2`。四档由端点推出：`log2(64 / 8) + 1 = 4`，无夹取。

**墨量**：`u = 4%`；`total = (n+1)u` → `8 / 12 / 16 / 20`；`inner = contact = u`；`outer = max(1, n−1)u` → `4 / 4 / 8 / 12`。全部是 `u` 的整数倍。

| 档 | contact | inner | outer | 总墨 | 角色 |
|---|---|---|---|---|---|
| 1 | `1/2 · 4%` | 空槽 | `2/8 · 4%` | 8% | control |
| 2 | `1/2 · 4%` | `2/8 · 4%` | `4/16 · 4%` | 12% | raised |
| 3 | `1/2 · 4%` | `4/16 · 4%` | `8/32 · 8%` | 16% | overlay |
| 4 | `1/2 · 4%` | `8/32 · 4%` | `16/64 · 12%` | 20% | deep |

- 表中 alpha 相加只描述配方标度，不是最终合成墨量；三层叠加的合成 alpha 是 `1 − Π(1 − aᵢ)`。
- 第 1 档的 inner 是空槽，不是缺结构（P10）。
- 场景常用 1–3 档；4 保留给大面积场景表面。浮层容器不用方向阴影，用环境遮蔽。

**单墨**：全项目一枚阴影墨，跟中性中段色相；明度取 `min(22, L_light − 12, L_dark − 6)`，保证墨暗于两端画布，不会变成辉光。环境偏色可覆写色相 / 彩度，`C ≤ 0.02`。各层共用同一枚墨，不按 contact / inner / outer 分色。

**深浅共用同一套墨与 alpha**，深色不做强度补偿。代价是深色下投影可能几乎不可见，这是黑底叠黑的物理上限。

## 5 框架、浮层与环境遮蔽

| 层 | 例子 | 主要分隔 |
|---|---|---|
| **框架** | navbar、tabbar、sidebar | `border` / 面阶 / 边缘高光；可选环境遮蔽；不用投影 |
| **浮层背景** | dialog / sheet / drawer 的遮罩 | 遮罩（半透明背景色，见 §3；不属光影） |
| **浮层容器** | dialog / sheet / drawer 的色块本体 | 环境遮蔽 + 边缘高光 / 材质；不用投影 |

**环境遮蔽四档**：居中、四边、无方向。

```text
blur_n  = 8 × 2^(n−1)   → 8 / 16 / 32 / 64
alpha_n = n × u         → 4% / 8% / 12% / 16%
offset  = 0
spread  = 0
```

- 只用纵深改变遮蔽强度与范围，不改变方向；与方向阴影共用同一枚墨。
- 框架贴边优先用描边 / 面阶；环境遮蔽只是「很浅的浮层感」。
- 浮层容器用环境遮蔽 + 边缘高光 / 材质；方向影被自己挡住，这是物理正确的。

**遮罩与环境遮蔽不是一个东西**：遮罩是全区域半透明背景色；环境遮蔽是元素边缘、四边、无方向。为什么不用投影：底部 sheet 的方向影落到屏幕外或被自己挡住；抽屉的向下影不能把抽屉和内容横向分开；四边遮蔽才是有效的分隔信号。

**角色落点**：`flat` = 无；`control` = 阴影 1；`raised` = 阴影 2；`overlay` = 阴影 3；`modal` = 遮罩（背景色）+ 环境遮蔽（容器）。

## 6 边界、边缘高光与明暗

**边界只有两种**：`border`（占布局的线）与 `outline`（不占布局的环，用于焦点）。背景色阶与阴影可以制造分块感，但它们不是边界。

**光影有四种**：

| 手段 | 形态 | 用途 |
|---|---|---|
| **阴影** | 外层投影，带偏移 / 模糊 | 场景的方向投影，表达高度 |
| **环境遮蔽** | 外层投影，偏移 0 | 框架 / 浮层容器的环境光遮蔽 |
| **边缘高光** | 外层 1px 环，白 5.8% | 掠射角的环境反射；浅色占位、深色生效 |
| **明暗** | 内层 inset，高光 / 遮光 | 表面形态（凸 / 凹） |

- 边缘高光是白色，两端同值，结构对称；它不是描边的替代，边界仍用描边 / 焦点环。
- 明暗的高光用高光偏色，遮光与边缘高光用环境偏色；方向由光源方位推出。
- 边缘高光 + 明暗 + 阴影才是一套完整拟物光影；材质（玻璃高光、背景模糊）归风格层。
- 浅色白面上白高光不可见；需要时用遮光或面差补足。可见值可以缺席，结构槽位不能缺席（P10）。

## 7 视觉深度 ≠ 堆叠顺序

- **视觉深度**：面差、投影、边缘高光、环境遮蔽表达的「离底面多远」。
- **堆叠顺序**：层叠上下文内的前后关系，由堆叠层级与顶层决定。

堆叠层级不成为设计值：绝对数字不承载设计承诺。使用方维护本地顺序，但保持同一套相对关系：`base < sticky < nav < mask < popup < toast`。

**顶层**（`dialog` / `popover`）脱离普通堆叠竞争，浮层移出父节点后继承与上下文由实现决定。

**深度的三条信号必须一致**：面差、投影、边缘高光 / 环境遮蔽不能互相打架（例如「更亮的卡片反而投更重的影」）。物理讲不通就不做。

## 8 深浅与性能

- **浅色靠描边 / 阴影 / 面阶，深色靠边缘高光 + 面差**，这是现行取舍，不是唯一答案。
- 投影只承诺方向与几何，不承诺深色可见度；暗墨在深色面上的可见性取决于墨色、alpha、模糊与实际背景。
- 边缘高光不是 WCAG 控制边界规范；它是装饰性高光边界，深色对比是否足够仍需人检。
- **成本来源**：模糊半径 × 覆盖面积 × 层数 × 是否动画。环境遮蔽是单层，成本低于三槽位阴影。
- **不要对投影做过渡**：层级变化瞬时切换即可；真要动画，走动效角色。
- **强制颜色**：阴影、文字阴影被强制为无，非 URL 背景图被移除——框架 / 浮层必须保留描边 / 背景遮罩 / 边缘高光兜底。
- **打印**：浏览器默认不打印背景色与阴影；框架的描边是更稳的分隔。

## 9 评审口径

**可检查项**：一级面容器是否按最坏背景验证合成对比度；底不可控时是否有底衬 / 遮罩 / 回退；面阶、阴影、环境遮蔽、边缘高光、明暗来自设计值；框架 / 浮层不出现方向投影；同一层级只有一种边界手段。

**项目自检**：墨块 / 遮罩的实际取值；材质使用与回退。

**必须人检**：半透明面叠在图片 / 视频 / 多层上的表现；遮罩在深色 / 自定义画布上的压暗；强制颜色 / 高对比 / 减少透明下的层级；场景方向一致性；环境遮蔽四边是否均匀；大模糊 + 多层的性能；去掉阴影后层级是否成立。
