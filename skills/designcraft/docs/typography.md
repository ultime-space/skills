# 排版规范

> 适用：字号取档、文字角色对齐、排版评审。
> 评审步骤见 [`scenarios/review-typography.md`](../scenarios/review-typography.md)。

## 1 字号

9 档：`10 / 12 / 14 / 16 / 18 / 20 / 24 / 32 / 40`。步长 `2 → 2 → 2 → 2 → 2 → 4 → 8 → 8`：小档密（UI 密度），大档疏（层级拉开）。

| 值 | 原生锚点 | 典型用途 |
|---|---|---|
| 40 | — | 展示主标题（可选） |
| 32 | `h1` | 一级页大标题 |
| 24 | `h2` | 页面标题 |
| 20 | — | 小节标题 / 大正文（可选） |
| 18 | `h3` | 卡片 / 分组标题；引导段 |
| 16 | `h4` / `p` | 正文基准；导航、列表主行同档 |
| 14 | `h5` | 摘要 / 说明 |
| 12 | `small` | 元信息 / 图注 / tag |
| 10 | `h6` | 极小注脚 / 底栏 |

> `small` 只作原生默认字号参照，不构成角色或新档。

规则：

1. **档名与值分离**：用序号命名，不用值当名字。
2. **范围只能减不能扩**：项目从 9 档里减；缺档在项目层覆盖，不往系统加档。
3. **可由基准与偏移派生**：字号阶梯可以由一个基准与一组偏移描述；项目可以整体平移或整套替换阶梯形状，不逐档改值。
4. **产品 UI 不单独加档**：同档跨屏；展示文档（纸面）按画布宽度换档，属例外。
5. **移动端只降内容、不降控件**：正文、文章标题可降一档（16 → 14、18 → 16）；按钮、导航等控件不降。

## 2 场景阶梯（取档指引）

倍数不是原料，是取档依据：先定基准档，再按倍数找最近档。系统只提供 9 档。

| 场景 | 基准 | 倍数 | 推导序列 | 落到九档 | 说明 |
|---|---|---|---|---|---|
| 长文 / 文档 | 16 | ×1.25 | 16 → 20 → 25 → 31 → 39 | 16 / 20 / 24 / 32 / 40 | 偏差 ≤1px，九档可直接承接 |
| 板块 / 演示 | 16 | ×1.5 | 16 → 24 → 36 → 54 | 16 / 24 / 32 / 40 | 36、54 无对应档，高端需项目自定义 |
| 海报 / 封面 | 16 | ×2 | 16 → 32 → 64 | 16 / 32 | 64 超出上限，必须项目自定义 |

- **只取最近档，不新增档**；需要精确值走项目覆盖。
- **一页最多四级**：超出部分用字重（400 / 500 / 600）与墨档（主 / 次 / 辅）承担。
- **倍数只是经验值**：×1.25 温和、×1.5 清楚、×2 强对比；不是可推导的约束。

## 3 字重

只用 `400 / 500 / 600`；`<b>` / `<strong>` 取 600。字重不单独成为设计值——它是 OpenType 常量，不是刻度。

- 层级跨字号，角色靠字重：标题与正文之间必须跨字号档；同一档内的差异由字重加区域隔离承担。
- 中文 700 及以上需验证合成加粗，不作为默认。
- 语义角色需配套字重规范：每个角色允许的字重、字号 ↔ 字重的最小搭配。

## 4 行高

4 档固定值，不按字号乘倍率派生：

| 档 | 值 | 用途 |
|---|---|---|
| **行高 1** | 1.2 | 单行 UI、大标题、大数字 |
| **行高 2** | 1.4 | 标题（多行下限）、说明与元信息 |
| **行高 3** | 1.6 | 正文与列表主文案 |
| **行高 4** | 1.8 | 长文正文 |

- 根行高 1 作基准。
- **单行垂直居中一律走居中布局**，禁止用行高制造居中或垂直间距。
- **段间距走间距档**，不取行高倍数。
- 可换行文字必须有显式行高，项目下限 1.4；1.2 只给单行元素。
- 需要与画布 / 网格做固定行高对齐时，允许显式行高 1，但只用于槽高必须确定的场景。

## 5 字距

一律用 em（随字号缩放）；中文按 em 计，不用 `ch`。

| 档 | 值 | 适用范围 |
|---|---|---|
| **字距 1** | −0.02em | 仅 ≥20px 的拉丁 / 数字 |
| **字距 2** | 0 | 中文一律用这档 |
| **字距 3** | 0.02em | 10–13px 小字略放 |
| **字距 4** | 0.04em | 全大写拉丁小标 |
| **字距 5** | 0.08em | 全大写拉丁（域名、英文标识） |

- 中文不加负字距；需要收紧时改字号档或字重。
- 拉丁收紧要挂在拉丁专属类（`.en` / `.num`）上，不靠中文继承。
- 负字距只出现在 ≥20px 的拉丁 / 数字；小字中文出现负字距按评审失败处理。

## 6 数字与中英混排

1. **数据比较用等宽数字**：`font-variant-numeric: tabular-nums`。
2. **半角空格是编辑约定**：中英 / 中数之间留一个半角空格；`text-autospace` 使用前核对平台支持，避免重复加空格。
3. **接口原文原样不动**：不替后端做排版清洗。
4. **换字体不改字号**：数字与中文分栈时，字号保持同一档。

## 7 文字角色

原子值管「落在哪一档」，角色管「哪些值可以打包」。角色不新增设计值。

| 角色 | 字号 | 字重 | 行高 | 字距 | 墨 | 对比门槛 |
|---|---|---|---|---|---|---|
| `display` | 32 | 600 | 1 | 0 | 主文字墨 | 3.0 |
| `page` | 24 | 600 | 1 | 0 | 主文字墨 | 3.0 |
| `card` | 18 | 600 | 2 | 0 | 主文字墨 | 4.5 |
| `nav` | 16 | 600 | 1 | 0 | 主文字墨 | 4.5 |
| `row` | 16 | 500 | 1 | 0 | 主文字墨 | 4.5 |
| `body` | 16 | 400 | 3 | 0 | 次文字墨 | 4.5 |
| `desc` | 14 | 400 | 3 | 0 | 次文字墨 | 4.5 |
| `meta` | 12 | 400 | 2 | 3 | 辅助文字墨 | 4.5 |
| `mini` | 10 | 500 | 1 | 0 | 辅助文字墨 | 4.5 |

- 大字号只认 WCAG 的两个阈值：≥24px 常规，或 ≥18.67px 粗体；`card` 18/600 按 4.5 处理。
- `nav` / `row` / `body` 同为 16 档，是原生 `h4` / `p` 的行为；差异靠字重与区域隔离。
- 墨档目标见 [`color.md`](./color.md) §3；辅助文字按普通文字门槛使用，不是图元档。
- `row` 仅用于单行；可换行的列表主行改用 `body` 或显式行高。
- 页面只认角色：字体简写、字号、字重、行高、字距只定义在角色层。
- 角色用到的每个字号档都必须在项目范围里；不做「角色对档位兜底」。

## 8 多语言

其他语言不 fork 整套设计值，而是在原料 + 角色上做 profile 覆盖。

| profile | 字体栈 | 行高 | 字距 | 断行 / 排版 | 行宽 |
|---|---|---|---|---|---|
| **zh-Hans** | Latin 先行 + 中文回退 | 1.6 / 1.8 | 0 | 严格断行；中西混排半角空格 | 34em |
| **en** | Latin 字体栈 | 1.6 | 仅 ≥20px 可用负字距 | 断词与换行控制 | 65ch |
| **ja** | 日文优先 + Latin 回退 | 1.6–1.8 | 0 | 严格断行；禁则 | 34em |
| **ko** | 韩文优先 + Latin 回退 | 1.6 | 0 | 按词断行，不拆词 | 36em |
| **ar** | Arabic 栈 | 1.6 | 0 | RTL；字距为 0 | 60ch |

- 用语言作用域控制，不靠全局继承。
- 组件只消费角色，不写语言分支；语言分支只在 profile 层。
- `lang` 表示语言，`dir` 表示基础方向，不能互相替代。
- 每个 profile 落地前，用真实字体实测行高、字距与断行。

## 9 字体接入与回退

| 情形 | 需要确认 |
|---|---|
| 系统字体栈 | 字形覆盖、区域字形、数字与符号的回退、平台间度量差异 |
| Web / 可变字体 | 许可、字重轴与 `@font-face` 声明、加载失败、主字体与回退字体的度量 |
| 加载策略 | `font-display` 的阻塞 / 交换取舍、缓存、必要的子集化与预加载 |
| 回退度量 | 基线、行盒、数字宽度、缺字与布局偏移 |
| 长标签 / 按钮 | 窄容器与译文增长时能否换行、扩高或重排 |
| 截断内容 | 是否仍能通过详情、展开或其它入口取得完整文本 |
| URL / 代码 / 表格 | 断行或局部滚动，保留复制与比较 |

**长文行宽**：正文段落建议控制在 34em 左右（16px 下约 34 个汉字；WCAG 1.4.8 对 CJK 的上限是 40 字）。容器太宽是内容侧问题，应收窄容器本身，不给段落设宽度上限。

## 10 行内图标与文字对齐

> 图标组、文字与圆角容器、控件与首行文字的对齐见 [optical-alignment](./optical-alignment.md)；本节只管行内图标与文字的垂直对位。

目标：图标在行盒内与文字视觉居中，等效于 `align-items: center`，但保持行内流动。

```css
.icon {
  inline-size: 1em;
  block-size: 1em;
  vertical-align: calc((1em - 1cap) / -2);
  flex: none;
}
```

`1em` 是字身框，`1cap` 是大写字母高度；两者之差的一半，就是图标盒中心与字面中线的距离。换字体、换字号自动跟随。

| 方案 | 与视觉中心的偏差 | 能否跨行 |
|---|---|---|
| 默认基线对齐 | 高 0.15em | 能 |
| 垂直居中对齐 | 低 0.10em | 能 |
| 固定 -0.125em 偏移 | 只在 cap = 0.75em 的字体上为 0 | 能 |
| **按（字身框 − 大写高）的一半反向下移** | ≤ 0.05em，随字体自动校正 | 能 |
| 弹性横排 + 垂直居中 | 0（对齐行盒） | 不能 |

边界：

1. 尺寸用 `1em`，不用 `1cap`；对齐靠公式补偿，不靠缩尺寸。
2. `cap` 单位有浏览器基线；不支持时回退到 `-0.125em`。
3. 行内正文保持 行高 ≥ 1.2。
4. 图标保持行内替换元素：不设 `display: block`、不用绝对定位。

## 11 评审口径

**可检查项**：字号落在档位；字重 ∈ {400, 500, 600}；行高来自档位；字距来自档位且中文无负值；文字四件套只定义在角色层。

**项目自检**：页面选择器里的文字四件套。

**必须人检**：200% 文字放大、窄视口重排、用户文字间距覆盖、长标题与译文增长、真实字体的裁切与可读性。
