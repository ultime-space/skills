# 排版规范（提炼）

> 源：Ultime `docs/design-system/05-typography.md`。本文件是面向 AI 的提炼，理由、验证方法与多语言 profile 以源为准。
> 适用：字号取档、文字角色对齐、排版评审。
> 评审步骤见 [`scenarios/review-typography.md`](../scenarios/review-typography.md)。

## 1 字号

9 档（`fs.1..9`）：`10 / 12 / 14 / 16 / 18 / 20 / 24 / 32 / 40`。
步长 `2 → 2 → 2 → 2 → 2 → 4 → 8 → 8`：小档密（UI 密度），大档疏（层级拉开）。

| 值 | 原生锚点 | 典型用途 |
|---|---|---|
| 40 | — | 展示主标题（可选） |
| 32 | `h1` | 一级页大标题 |
| 24 | `h2` | 页面标题 |
| 20 | — | 小节标题 / 大正文（可选） |
| 18 | `h3` | 卡片 / 分组标题；引导段 |
| 16 | `h4` / `p` | 正文基准；导航、列表主行同档 |
| 14 | `h5` | 摘要 / 说明 |
| 12 | `small` | 元信息 / 图注 / tag |
| 10 | `h6` | 极小注脚 / 底栏 |

规则：

1. **档名与值分离**：用序号命名，不用 `--fs-16` 这类值名。
2. **子集只能减不能扩**：项目从 9 档里减；缺档在上层覆盖，不往内核加档。
3. **可派生**：seed 给 `base` 与 `steps`，档值 = `base + steps[n]`；配置器只改 `base`（全档平移），`steps` 只能整体替换，**不允许逐档改值**。
4. **产品 UI 不单独加档**：同档跨屏；展示文档（纸面）按画布宽度换档，属例外。
5. **移动端只降内容、不降控件**：正文、文章标题可降一档（16 → 14、18 → 16）；按钮、导航等控件不降。

## 2 场景阶梯（取档指引）

倍数不是原料，是**取档依据**：先定基准档，再按倍数找最近档。内核只提供 9 档。

| 场景 | 基准 | 倍数 | 推导序列 | 落到内核档 | 说明 |
|---|---|---|---|---|---|
| 长文 / 文档 | 16 | ×1.25 | 16 → 20 → 25 → 31 → 39 | 16 / 20 / 24 / 32 / 40 | 偏差 ≤1px，九档可直接承接 |
| 板块 / 演示 | 16 | ×1.5 | 16 → 24 → 36 → 54 | 16 / 24 / 32 / 40 | 36、54 无对应档，高端需覆盖 |
| 海报 / 封面 | 16 | ×2 | 16 → 32 → 64 | 16 / 32 | 64 超出上限，必须覆盖 |

- **只取最近档，不新增档**；需要精确值走项目覆盖。
- **一页最多四级**：超出部分用字重（400 / 500 / 600）与墨档（primary / secondary / tertiary）承担。
- **倍数只是经验值**：×1.25 温和、×1.5 清楚、×2 强对比；不是可推导的约束。

## 3 字重

只用 `400 / 500 / 600`；`<b>` / `<strong>` 取 600。字重**不产物 token**（OpenType 常量，不是刻度）。

- 层级跨字号，角色靠字重：标题与正文之间必须跨字号档；同一档内的差异由字重加区域隔离承担。
- 中文 700 及以上需验证合成加粗，不作为默认。

## 4 行高

4 档固定值，不按字号乘倍率派生：

| 档 | 值 | 用途 |
|---|---|---|
| `lh.1` | 1.2 | 单行 UI、大标题、大数字 |
| `lh.2` | 1.4 | 标题（多行下限）、说明与元信息 |
| `lh.3` | 1.6 | 正文与列表主文案 |
| `lh.4` | 1.8 | 长文正文 |

- 根 `line-height: 1` 作 base。
- **单行垂直居中一律走 flex**，禁止用 `line-height` 制造居中或垂直间距。
- **段间距走 `space.*`**，不取行高倍数。
- 可换行文字必须有显式行高，项目下限 1.4。

## 5 字距

一律用 em（随字号缩放）；中文按 em 计，不用 `ch`。

| 档 | 值 | 适用范围 |
|---|---|---|
| `ls.1` | −0.02em | 仅 ≥20px 的拉丁 / 数字 |
| `ls.2` | 0 | 中文一律用这档 |
| `ls.3` | 0.02em | 10–13px 小字略放 |
| `ls.4` | 0.04em | 全大写拉丁小标 |
| `ls.5` | 0.08em | 全大写拉丁（域名、英文标识） |

- 中文不加负字距；需要收紧时改字号档或字重。
- 拉丁收紧要挂在拉丁专属类（`.en` / `.num`）上。

## 6 文字角色

原子值管「落在哪一档」，角色管「哪些值可以打包」。角色**不新增 token**。

| 角色 | 字号 | 字重 | 行高 | 字距 | 墨 |
|---|---|---|---|---|---|
| `display` | 32 | 600 | `lh.1` | 0 | primary |
| `page` | 24 | 600 | `lh.1` | 0 | primary |
| `card` | 18 | 600 | `lh.2` | 0 | primary |
| `nav` | 16 | 600 | `lh.1` | 0 | primary |
| `row` | 16 | 500 | `lh.1` | 0 | primary |
| `body` | 16 | 400 | `lh.3` | 0 | secondary |
| `desc` | 14 | 400 | `lh.3` | 0 | secondary |
| `meta` | 12 | 400 | `lh.2` | `ls.3` | tertiary |
| `mini` | 10 | 500 | `lh.1` | 0 | tertiary |

- `nav` / `row` / `body` 同为 16 档，是原生 `h4` / `p` 的行为；差异靠字重与区域隔离。
- 墨档目标见 [color.md §3](./color.md)；`tertiary` 按普通文字门槛使用，不是图元档。
- 页面只认角色：`font` 简写、`font-size`、`font-weight`、`line-height`、`letter-spacing` 只定义在角色层。

## 7 评审口径

**core / 语义表可机检**：字号落在档位；字重 ∈ {400, 500, 600}；行高来自档位；字距来自档位且中文无负值。

**项目自检（不是 core 合同）**：页面选择器里的文字四件套。

**必须人检**：200% 文字放大、窄视口重排、用户文字间距覆盖、长标题与译文增长、真实字体的裁切与可读性。
