# 布局与构图规范

> 源：设计规范 §11（快照 2026-11-05）。本文件是面向 AI 的提炼，不是规范真源。
> 适用：页面结构、滚动归属、栅格与容器、断点、响应式、页面级构图评审。
> 评审步骤见 [`scenarios/review-structure.md`](../scenarios/review-structure.md)。

## 1 先决定谁滚动、谁常驻、谁让位

页面结构不是先画 header，而是先回答四个问题：

1. **哪个区域滚动**：整页滚动、内容区滚动、侧栏独立滚动，三者不能互相嵌套失控。
2. **哪些元素常驻**：navbar / tabbar / sidebar / 操作栏是否 sticky / fixed；遮挡内容时如何补偿。
3. **小屏如何退化**：侧栏变抽屉、底部导航替代、还是保持双列横向滚动。
4. **焦点如何进入**：跳过导航链接、抽屉关闭后焦点回到触发点、滚动容器可键盘操作。

**单滚动原则**：一个页面只保留一个主滚动容器。navbar 用 `position: sticky`，tabbar 放在滚动容器外；内容超出只让主滚动容器滚，页面本身不滚。多重滚动会让滚动位置、焦点与吸顶行为互相打架。

**安全区**：全出血布局让出 `env(safe-area-inset-*)`；固定底栏加安全区内边距，不加空白元素假装。

**应用壳层的最小配方**：

```text
page（整屏，100dvh；overflow: hidden）
 ├── scroll（唯一滚动容器）
 │    ├── navbar（sticky 顶部，固定高度，不被内容撑高）
 │    └── content wrap（限宽 + 左右内边距）
 └── tabbar / submit-bar（滚动容器外，固定底部 + 安全区）
```

- 状态栏、胶囊、设备控件属于设备壳，不是页面内容；页面只负责让出安全区与底色。
- navbar 固定高度：左右槽位等宽，标题单行；标题再长也不换行撑高。
- tabbar 背景不透明；顶部可用 1px 分隔线，不用投影。
- 深色下 navbar / tabbar 用中性面映射，不引入品牌色。

## 2 栅格与容器

**两类栅格不要混用**：

| 角色 | 用在哪 | 列数 | 说明 |
|---|---|---|---|
| **内容栅格** | 设备屏内页面 / 卡片 / 表单 | 4 / 8 / 12 | 由容器与断点决定 |
| **展示栅格** | 画布上的纸面（规范页 / 海报 / 素材） | 24 | 展示示例；24 是 12 的倍数，能表达 1/8 |

**页面留白**：端点 16 / 32，中间连续插值，`clamp(16px, 16px + (100% - 320px) / 80, 32px)`；用 `100%` 而不是 `100vw`（`vw` 包含滚动条）。适用范围 `320 → 1600`；更宽的屏只增加外边距，不拉宽内容。

**内容上限**：单值 1440，超出居中；更窄的阅读容器显式选 960 / 1200。

**阅读行宽**：中文正文约 34em，英文约 65ch；行宽是内容侧问题，应收窄容器本身，不给段落设宽度上限。

**面宽 / 分栏**：`pane` 最小宽 320–360；宽度阶梯、卡片 / 弹窗 / 抽屉的固定档归组件层，不在本文件预建。

**内衬与间距同源**：`padding` 取间距档，不另立内衬刻度；同心圆角要求 padding 是圆角基座的倍数。

## 3 断点与内容驱动换行

- **断点只做设计沟通参考线**（600 / 840 / 1200 / 1600），不进设计值；设备宽度已经碎片化，主流口径是「由内容决定」。
- **从视口下移到内容**：可复用组件用容器查询；页面级导航切换仍需要页面容器决定。
- **内容驱动换行**：换行点 = `n × 最小宽 + (n−1) × 间距`，只看容器宽，与视口无关。
- **断点单位**：媒体查询里的 `em` / `rem` 按浏览器初始字号计算，不跟随页面根字号；用 px 断点更可预测。
- **密度不随断点自动切换**：否则旋转屏幕后布局会跳变；密度只由页面显式声明。

## 4 构图模式

| 模式 | 结构 | 适合 | 容易失效 |
|---|---|---|---|
| **文档流 / 堆叠** | 单列内容、标题与段落 | 阅读、说明、设置 | 行宽过长；用 margin 叠间距 |
| **固定列栅格** | 12 / 24 列 + 跨度 | 后台、仪表盘 | 列宽被当内容宽；窄容器失真 |
| **比例分栏** | 2/3 + 1/3、主辅面板 | 详情 + 辅助信息 | 小屏不堆叠；正文过宽 |
| **列表-详情** | 左列表 + 右详情 | 消息、邮件、设置 | 小屏切换、返回路径、滚动位置 |
| **卡片墙 / feed** | 数量不定、等高或不等高 | 内容集合、作品集 | 最后一行拉伸、长内容撑破 |
| **仪表盘 / bento** | 小部件按优先级拼格 | 数据概览 | 小屏重排后顺序与重要性不符 |
| **数据表格** | 多列、可比较 | 后台、报表 | 二维滚动；堆叠后失去比较 |
| **表单** | 标签 + 控件 + 提示 | 录入、设置 | 标签位置、错误位置、缩放换行 |
| **阅读型** | 正文 + 目录 + 注释 | 长文、协议、帮助 | 行宽、长文导航、打印 |
| **画廊** | 图片集合 | 素材、作品 | 加载位移、裁切、alt |
| **空态 / 错误态** | 说明 + 下一步 | 无数据、失败 | 只放插画，不给原因与动作 |

**选择顺序**：先看内容关系（单条 / 列表 / 主辅 / 比较），再看容器宽度，最后看平台惯例。不要先选「卡片网格」再往里塞内容。

## 5 响应式与重排

- **移动优先**：默认单列，按可用宽逐步增加列 / 侧栏；不做「桌面版缩水」。
- **视觉重排不改变 DOM 顺序**：`order`、`grid-auto-flow: dense`、绝对定位都能让视觉顺序与源码顺序分离；WCAG 2.4.3 要求焦点顺序保持意义与可操作性。
- **320px 重排**：WCAG 1.4.10 要求 320 CSS px 下不出现二维滚动（例外除外）；表格用横向滚动壳、列优先或堆叠，三选一，不能默认堆叠成卡片而失去比较。
- **200% 文字缩放**：不裁切、不重叠、不丢功能；固定高度与 `nowrap` 不是安全保证。
- **RTL**：优先逻辑属性与 `dir`，不要用 `direction` 临时翻转；方向性图标才翻转，数字与代码保持原方向。
- **打印**：打印是另一套布局；隐藏导航、展开链接、控制分页，不把屏幕布局直接打印。
- **长内容**：标题平衡换行、长 URL / 标识可断行、chip / tag 可换行或 `+n` 展开；截断必须有完整的可访问路径。

## 6 反模式

- 多个滚动容器互相嵌套，滚动位置与吸顶行为失控。
- 用固定宽度 / 固定高度撑布局，窄容器或译文增长时溢出。
- 所有内容都做成卡片网格；没有层级，只有格子。
- 居中 hero + 三列卡片 + 紫色渐变，作为默认首页。
- 小屏隐藏次要内容但没有入口；或把表格堆叠成卡片后失去跨行比较。
- 用绝对定位做常规布局；用堆叠层级数值解决层叠语义。
- 用 `100vw` 做全宽，忽略滚动条；用 `overflow-x: hidden` 掩盖真正的溢出。
- 用断点切换密度，导致旋转屏幕后布局跳变。

## 7 评审口径

**可检查项**：单滚动容器；navbar / tabbar 常驻；安全区；页面留白端点；内容上限；断点只做参考线。

**必须人检**：320px 重排、200% 文字缩放、容器查询 / 内容驱动换行、DOM 顺序与焦点顺序、表格三种降级、空态 / 错误态 / 加载态、RTL / 打印、固定元素不遮挡焦点。
