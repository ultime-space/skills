## 同步责任

- 源是内部设计规范；本目录是面向 AI 的提炼。
- 源改动时，本目录必须跟；判断标准是「同一条规则在两处的表述是否一致」，不是行数。
- 提炼可删减、合并与重排（以评审可用性为先），但不能新增源里没有的规则；需要新增规则时先改源，再同步过来。
- 本目录不写产品名、实现术语、工具命令与强制检查；只写设计知识、建议与评审口径。
- 最近同步：2026-11-05（补一级面容器可读性风险口径、动效可打断 / 来去路径 / 常用模式 / 曲线选择；此前已覆盖原则、语言、流程、颜色、排版、空间与形状、布局、表面与光影、交互状态、数据 / 图形 / 内容、构图、评审与风格）。
