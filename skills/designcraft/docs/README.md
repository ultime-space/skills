## 同步责任

- 源是 Ultime 内部的 `docs/design-system/design.md`（不对外分发）；本目录是对外载体。
- 源改动时，本目录必须跟；判断标准是「同一条规则在两处的表述是否一致」，不是行数。
- 提炼可删减、合并与重排（以评审可用性为先），但不能新增源里没有的规则；需要新增规则时先改源，再同步过来。
- 最近同步：2026-11-04（颜色：三条文字线 / `foreground` 配对槽位 / L 等距 / 审计不阻断；排版：大字号门槛）。
- 暂不做源同步的自动构建：当前规模下手工同步成本低于构建流水线；结构、版本与链接由 `npm test` / CI 检查。
