## 同步责任

- 源在 Ultime 仓库的 `docs/design-system/`；本目录是它的**提炼**，不复制理由、历史与多语言 profile。
- 源改动时，本目录必须跟；判断标准是「同一条规则在两处的表述是否一致」，不是行数。
- 提炼只能**删减与压缩**，不能新增源里没有的规则；需要新增规则时先改源，再同步过来。
- 最近同步：2026-11-04（颜色：三条文字线 / `on` 独立维度 / 审计分级；排版：无值变更，仅边界与引用）。
- 暂不做源同步的自动构建：当前规模下手工同步成本低于构建流水线；结构、版本与链接由 `npm test` / CI 检查。
