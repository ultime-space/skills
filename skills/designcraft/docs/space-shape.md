# 空间与形状规范

> 源：设计规范 §6（快照 2026-11-05）。本文件是面向 AI 的提炼，不是规范真源。
> 适用：间距、控件高度、密度、热区、圆角、边界、焦点与选中评审。
> 评审步骤见 [`scenarios/review-structure.md`](../scenarios/review-structure.md)。

## 1 四个量必须分开

| 量 | 回答 | 单位 | 典型混用 |
|---|---|---|---|
| **间距** | 两个盒子隔多远 | rem | 用 `margin` 造块间距；把光学档外溢到布局 |
| **尺寸** | 控件视觉上画多高 | rem | 把控件高度当热区 |
| **圆角** | 角收多圆 | rem | 内外同半径；用经验比例代替裁切验证 |
| **边界** | 有没有一条线、多粗、什么线 | px | 用投影环当边界；状态加粗改几何 |

另外三个量容易被顺手塞进来：**可点目标**（§4）、**行密度**（§3）、**页面布局**（`layout.md`）。

## 2 间距与基座

**布局基座取 4，推荐 8 的倍数。** `12` 是真实界面的高频档：卡片内衬 16、卡内子块 12 是配套关系。砍掉它，紧凑布局只能在 8 和 16 里二选一，最后一定有人手写 `12px`。

| 组 | 档（px） | 用在哪 |
|---|---|---|
| **光学** | 2 / 6 | 只允许组件内部修正：图标与文字、标签上下、轨道 |
| **紧凑段** | 4 / 8 / 12 / 16 / 20 / 24 | 行内、卡内与常规布局；4 同时是最小布局档 |
| **布局段** | 32 / 40 / 48 / 56 / 64 / 72 / 80 | 分组、区块、大留白 |
| **宽屏段** | 96 / 120 / 160 | 平板 / 宽屏的空态、大留白、分栏间隙 |

**光学档 2 / 6 只服务组件内部**，且必须引用登记值，不写字面量。准入三条同时满足：

1. 只出现在组件内部，不外溢到布局；
2. 只能引用设计值，不写 `2px` / `6px`；
3. 组件注释登记「光学档」，且不参与语义阶梯与密度。

**语义角色按用途选**：

| 角色 | 指向 | 用途 |
|---|---|---|
| 行内间距 | 4 | 图标 ↔ 文字、标签 ↔ 标签（光学，不参与密度） |
| 组内间距 | 8 | 同组相邻元素 |
| 卡内间距 | 12 | 卡片内子块之间 |
| 卡片内衬 | 16 | 卡片内衬 |
| 卡片间距 | 24 | 同一分组内的两张卡 |
| 分组间距 | 32 | 分组之间、首尾与吸底栏 |
| 页面留白端点 | 16 | 页面留白端点 |

**禁止用 `margin` 制造块间距**：块间距用父容器 `gap` 或占位；`margin` 只表达组件自身与相邻元素的关系。布局值必须取 4 的倍数；需要半档时用已有档，不写一次性数值。

## 3 控件高度与密度

五档控件高度与间距共用几何基（4）：`24 / 32 / 40 / 48 / 56`。

| 档 | 高（px） | 用途 |
|---|---|---|
| 1 | 24 | 密集表格行、极小标签 |
| 2 | 32 | 紧凑按钮 / 输入、列表小行 |
| 3 | 40 | 桌面 / 平板默认控件 |
| 4 | 48 | 移动 / 触控默认控件、主按钮 |
| 5 | 56 | 大按钮、重点输入 |

- 5 档全保留，不补 16 / 20 / 36 / 64；尺寸只是视觉高度，目标尺寸归 §4。
- 列表行高 = 控件高 + 上下内衬；内衬走间距档。
- 默认档是角色，不是常量：移动用触控档（48）、平板 / 桌面用默认档（40）、密集表格用紧凑档（32）、主按钮用强调档（56）。

**密度是角色重映射，不是第二套值**：

| 机制 | 作用范围 | 改什么 | 不改什么 |
|---|---|---|---|
| **尺寸档** | 单个组件 | 控件视觉高、内衬、字号、图标、间距 | 页面整体疏密 |
| **密度档** | 整页 | 角色的指向 | 原料值、字号、圆角、图标 |

| 角色 | comfortable | compact |
|---|---|---|
| 卡片内衬 | 16 | 12 |
| 卡片间距 | 24 | 16 |
| 分组间距 | 32 | 24 |
| 默认控件 | 40 | 32 |
| 触控控件 | 48 | 40 |
| 强调控件 | 56 | 56 |

三条约束：

1. 同一页面不混用两种密度，局部紧凑用尺寸档解决；
2. 密度不随窗口宽度自动切换，否则旋转屏幕后布局会跳变；
3. 密度只由页面显式声明，不由断点或横竖屏推断。

## 4 热区与目标尺寸

**三层分开**：视觉尺寸、热区、相邻目标间距，分别验证。图标画 16 / 20 / 24 不代表热区也是这个尺寸。

| 来源 | 口径 |
|---|---|
| WCAG 2.2 | AA 为 24×24 CSS px（含例外）；AAA 为 44×44 |
| Apple HIG | iOS 默认 44×44pt、最小 28×28pt；macOS 28 / 20 |
| Material 3 | 默认 48×48dp，密度不得把目标降到 48 以下 |
| Fluent 2 | Web 44×44；Android 48×48 |

**44 是默认主张，不是跨平台物理常量。** 适用端是移动与平板；指针环境可到 28–32。

组件层决定交互根怎么达到 44：

- 推荐把根做成骨架，根高 `max(44, 视觉尺寸)`，视觉盒在内层；
- 同一行同一档根高一致；混档行由行原语取最大值；
- 外扩不能盖住邻近目标；相邻间距本身也可以承担部分隔离。

**compact 必须先回答热区怎么做**：缩小视觉高度后，优先用根骨架托底；其次透明外扩或保证相邻间距；或者明确该场景不使用紧凑密度。不能只改高度就宣称「密度支持」。

## 5 圆角与同心嵌套

圆角由基准派生：默认基座 4、9 档，得到 `0 / 4 / 8 / 12 / 16 / 20 / 24 / 28 / 32`。

- 圆角基座与布局间距共用几何基；改基座时间距与圆角一起变。
- 语义指向：极小 4、小 8、控件 12、输入 12、卡片 16、面板 24、大面 32。
- **输入跟控件同档**：输入 / 选择 / 多行与按钮同属「控件」层，同指 12；8 只留给内块 / 缩略图。
- 胶囊归组件层：用高度一半或足够大的值夹紧，不进系统刻度。
- 非均匀圆角属显式定制，默认走基座派生。

**同心嵌套**：贴近外角、且内外间隙等宽时，`内半径 = 外半径 − 内衬`。

四个条件同时满足才成立：

1. **内层贴角**：内块离角部较远时，不必严格套公式。
2. **内衬等宽**：内衬来自布局间距，四面一致，且是圆角基座的倍数。
3. **结果为正**：0 是直角，负值无效。
4. **不做同心的场景**：非对称内衬（安全区）、胶囊、内外高度不同、内层不贴角时，各自取半径。

**内容避让**：内容触及角落时会长到圆角外，需要内衬或按圆角内接矩形收缩内容。`0.3 × 外半径` 是经验起点，不能替代实际角部轮廓的裁切验证。

**相邻圆角不重叠**：CSS 按每条边两端半径之和与边长归一化，不是「每个角 ×2」。「圆角 × 2 ≤ 短边」只在四角等半径时成立。

## 6 边界、焦点与选中

### 6.1 边界只有 border / outline

| 手段 | 占布局 | 跟随圆角 | 典型用途 | 主要风险 |
|---|---|---|---|---|
| `border` | 是 | 是 | 控件边界、卡片描边、分隔 | 加宽会改变尺寸 |
| `outline` | 否 | 是 | 键盘焦点、强制颜色 | 可能被祖先 `overflow` 裁掉 |

背景色阶与阴影可以制造分块感，但它们不是边界：不画一条可辨识的线，也不承担边界职责。深色浮层的高光边界是边缘高光，属光影。

**同一层级只允许一种边界手段**：卡片是底色阶，纸内就用井；不要「卡片阴影 + 卡片描边」叠两层。

| 需求 | 手段 | 理由 |
|---|---|---|
| 静态围合（控件、输入、卡片） | `border` 1px | 占布局，但结构稳定 |
| 分隔（列表行、表格、区块） | 单侧 `border` 1px，或间距 + 面阶 | 线只在一侧 |
| 选中 / 激活 | `outline` 或内嵌环，2px | 不占布局，切换不跳动 |
| 键盘焦点 | `outline` 2px + offset | 可与选中并存 |
| 深色浮层边缘 | 边缘高光 | 不是边界 |
| 分层 | 面阶 | 线不表达层级 |
| 粗指示（进度、选中条、引用竖线） | 填充块，高度取间距档 | 那是形状，不是描边 |
| 未完成 / 可放置 | `dashed` 1px | 只表达占位 |

- **重量不设阶梯**：1px 是一条线的表达，2px 是焦点面积下限，0.5px 是设备 1 物理像素的近似；都不是风格选择。
- **粗线不是线**：3 / 4px 的用例是填充形状，改用色块。
- **线型只有两种**：`solid` 是结构性边界；`dashed` 只表达未完成 / 可放置 / 占位。`dotted` 不采用。
- **状态不加宽**：选中 / 焦点 / 错误一律用不占布局的手段。

三档描边的对比度目标：**1.16 / 1.45 / 3.0**。1.16 用于分隔线与装饰边界；1.45 用于控件轮廓；3.0 用于边界本身承担识别（WCAG 1.4.11）。叠在图片 / 彩色块上时对比度随底变化，只承诺中性面。

### 6.2 焦点与选中是两件事

| | 键盘焦点 | 选中 / 激活 |
|---|---|---|
| 画法 | `outline` + `outline-offset` | 不占布局的 2px 环 + 主色 |
| 是否占布局 | 否 | 否 |
| 何时出现 | `:focus-visible` | 数据状态 |
| 标准 | 1.4.11 相邻颜色 3:1；2.4.13 指示面积另算 | 1.4.11（若边界用于识别控件） |

两者可以同时出现，但不能用其中一个替代另一个。

- 强制颜色模式下不要抹掉 `outline`。
- 用 2px `border` 加宽表达选中会改变尺寸并触发重排；改走不占布局的手段。
- 祖先的 `overflow`、滚动壳、sticky header、弹层都可能裁掉或盖住焦点环。
- WCAG 2.4.11（AA）要求聚焦组件不被完全遮挡；2.4.12（AAA）要求任何部分都不被遮挡。

## 7 评审口径

**可检查项**：间距落在项目范围、布局值是 4 的倍数；控件高度落在五档；圆角落在派生集；描边宽度 ∈ {1, 2}、线型 ∈ {solid, dashed}、线色为引用。

**项目自检**：光学档只引用登记值；组件内部不写字面量。

**必须人检**：视觉尺寸 / 热区 / 相邻间距三个值；compact 下的热区兜底；同心公式与内容内衬；焦点环是否被裁切；选中与焦点能否区分；320px 重排与 200% 文字缩放。
