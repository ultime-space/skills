# 真实页面评审样本

> 用途：用 2026-11-19 的实际页面截图回放默认排序；页面已抽象命名，不含内部路径与产品名。
> 状态：样本（2026-11-19）。**不是历史项目报告**：修改顺序是评审时给出的，不是事后观察到的真实修改顺序。

## 回放方法

1. 只读报告，不看末尾的「建议修改顺序」。
2. 按默认排序重排：跨切 → 共享规则 → 任务 → 结构 → 对齐 → 层级 → 交互 → 适配。
3. 与建议顺序对比；不一致时记录原因，不强行改规范。

## 回放结论

| 报告 | 默认排序 | 例外 |
|---|---|---|
| 01 | 成立 | 底部遮挡归「跨切」而不是「适配」，因为它同时影响可达性与任务完成 |
| 02 | 成立 | 无 |
| 03 | 成立 | 适配项只到「未验证」，没有足够证据下结论 |

结论：默认排序在 3 份真实页面样本上成立；「影响可达性 / 任务完成时可以提前」的例外是必要的，不需要新增顺序。
