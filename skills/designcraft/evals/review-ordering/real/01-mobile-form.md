# 评审报告：移动端表单页

> 真实页面样本（2026-11-19）；不是历史项目报告。

## 结论

`warn`：表单可用，但底部浮动工具条遮挡内容，错误恢复也偏弱。

## 范围

移动端表单页，1400 × 900 视口；浅色；最坏内容：校验错误、禁用选项、底部操作。

## 证据

- 底部浮动工具条覆盖表单最后一行控件，滚动前后都压在内容上。
- 错误只出现在字段下方，没有错误汇总；提交后不回到第一个错误。
- 页面标题与分组标题之间的留白明显大于组内间距。
- 分组标题与稿面标签同时存在，层级略重。
- 输入 / 选择的高度与圆角一致，未发现档位漂移。
- 标签、输入、错误文案左对齐一致。

## 建议修改顺序

1. 底部遮挡（跨切：可达性与任务完成）。
2. 错误汇总与回到第一个错误（任务）。
3. 标题留白（结构）。
4. 双重标注（层级）。
5. 其余项通过，不改。

## 例外说明

底部遮挡属于适配 / 布局，但同时遮住可操作控件，按「影响可达性 / 任务完成可提前」归到跨切。默认排序不需要新增顺序。
