# 评审排序回放样本

> 用途：验证 [`scenarios/review-critique.md`](../../scenarios/review-critique.md) 的默认排序在真实评审结构上是否稳定。

三份都是**构造样本**，不是历史项目记录；只用于回放，不证明真实修改顺序，也不作为规范结论。

## 回放方法

1. 只读报告，不看报告末尾的修改顺序。
2. 按默认排序重排问题：跨切 → 共享规则 → 任务 → 结构 → 对齐 → 层级 → 交互 → 适配。
3. 与报告里的「构造时的修改顺序」对比；不一致时记录原因，不强行改规范。

## 样本

- [`01-checkout.md`](./01-checkout.md)：表单、错误恢复、窄屏。
- [`02-dashboard.md`](./02-dashboard.md)：数据层级、状态色、动效。
- [`03-settings.md`](./03-settings.md)：危险操作、保存反馈、200% 放大。
