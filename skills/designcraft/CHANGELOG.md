## 0.11.0

- 新增 `docs/project-types.md`：类型倾向层。8 张类型卡（官网 / 品牌、门户 / 内容、电商 / 交易、工具 / 效率、社区 / UGC、后台 / 管理、游戏 / 娱乐、公共服务 / 适老）与 10 张角色卡（入口、索引 / 列表、搜索与无结果、详情 / 产品页、内容阅读、表单 / 流程、账户 / 设置、专题 / 方案 / 案例、状态页、帮助 / 联系）。
- 类型卡只写目标与阶段、首屏、典型二级页、倾向、常见错误与不适用；角色卡只写要回答什么、必需元素、常见结构、对应 S 条目、平台差异、常见错误与业务可自定；都不写成模板或硬规则。游戏类型缺专门调研，只作方向提示，不列固定页面清单。
- 角色优先于类型：类型只调权重，同一页面的角色任务不被类型覆盖；输出只取对应两张卡，不填满 8 × 10 矩阵。
- 新增「平台运行时约束」与「规范硬要求」两节：小程序包体与标签栏约束、iOS / Android 标签与安全区、WCAG 与国内适老条款、三套触控目标不可互换、首屏性能指标；规范摘录只用于检查，不写成阻断结论。
- 新增「适老与无障碍：经验与写法」：硬要求只留指针，认知经验不与硬要求混写，也不把无障碍降成风格偏好。
- `SKILL.md` 补类型倾向路由与工作流；`docs/README.md` 补索引与归属；`prompts/output.md` 新增「类型与角色对照」格式，方案集范围补类型与阶段；`templates/option-set.md` 同步；`scenarios/refine.md` 出方案前先取类型卡与角色卡。
- 新增 evals：12 个类型 × 角色样本与 3 个轻量样本，覆盖首屏阶段、每页一个主动作、无结果页、列表密度、移动版退法、平台硬限制与适老分层；回归补只读详情、类型复合、图片站与游戏专用界面 3 条，以及无支持诊断、证据不足与报告边界 3 条。
- 结构测试新增 `docs/project-types.md` 必需文件、卡片数量与字段检查、卡片行数预算、S 条目引用有效性，以及只读详情、类型复合与 Refine 诊断闸门的回归守卫。
- 按 0.10.0 的 12 个试跑样本做 0.11.0 回归：结构结论全部保持；修正 4 个类型层问题——R4 / S1 补只读详情（无主行动时给明确出口）、补「类型可复合」取类规则、T1 补图片站不适用、T7 补专用记分 / 对局界面不适用。
- `README.md` 补类型倾向的输入输出与「类型倾向 + 结构方案」组合用法；`CONTRIBUTING.md` 补发布前自检（版本、测试、打包清单、独立代理回归、由维护者发布）。
- Refine 重构为四段机制：证据与目标 → 诊断闸门 → 方案生成 → 交付校验。新增诊断三证（现象 / 影响 / 可改）、默认套路扫描、无支持诊断的停止条件、交付前三问，以及「只出 Markdown 方案集、不产出 HTML、不改文件」的报告边界；模板与输出格式同步，不新增档位或条目。
- 设计原则补 P18「自描述优先」：元素或代码自身能表达的不再加说明文字或复述式注释；说明只补可访问名称、错误原因、空态出口、数据出处等自身表达不了的信息。新增对应 eval 与测试守卫。

## 0.10.0

- 新增 `docs/patterns.md`：结构方案库。先按内容关系（单条 / 同构集合 / 比较集合 / 主辅 / 序列 / 录入 / 异构聚合）定可选上限，再按目标与最坏内容选变体，代价只记可比较性、一屏信息量、定位成本与最坏内容风险。
- 收录结构方案：详情页分层、长内容披露位置、同构集合单元形态与密度、集合分组、表格与卡片列表的取舍、多列数据窄屏退法、主辅并置与退法、序列结构、表单标签位置与栏数、异构卡片聚合。
- 收录状态姿态：空态三语义、表单错误两处呈现、加载姿态；状态语义仍由 `docs/states.md` 拥有，本文件只讲摆放。
- 新增 `scenarios/refine.md`：Refine 模式。已有页面只调结构、排列、主次与密度，出 2–3 套方案；A 排列级默认开放，B 结构级需同意。
- 新增 `templates/option-set.md` 与 `prompts/output.md` 的「方案集」格式。
- `SKILL.md`：模式表新增 Refine，路由表新增结构方案一行；`docs/README.md` 补索引与归属，并注明方案库是经验而非规则。
- 新增 evals：同构集合方案、详情页与长文案、仪表盘密度、方案集边界。
- 结构测试新增 `docs/patterns.md`、`scenarios/refine.md`、`templates/option-set.md` 必需文件与「每条方案保留五个字段」检查。
- 新增 P14「条件块与互斥结构」、P15「长文本的容器分配」；P3 补整除与「图先于名」；P10 补按用途分组。
- 代价由四项扩为五项，新增**一致性**：页内混用两种形态是代价，跨页槽位漂移是违背约定。
- 新增「页面族约定」：管理端与移动端的新增、条目操作、筛选、提交、危险操作各固定一个槽位；Refine 只检查与提示，不改全站。
- `templates/option-set.md` 与 `prompts/output.md` 同步五项代价与约定检查；evals 新增页面族约定、同页混用、只有设计稿三条。
- 新增 P16「整幅内容的放置」：不可拆块走集中段 / 带尾单次 / 横向序列，不参与网格；同屏数量随视觉重量下降。
- Refine 输入补「证据来源」：设计稿、实现或两者，不一致以实现为准；设计稿若是实现镜像只取视觉意图与比例。
- 明确空态、加载、错误态与最坏内容不会随输入自带，必须显式问或标注为假设；evals 新增设计稿与实现不一致、整幅块两条。
- 风格输出改为方案集：2–3 套方向，每套写意图、维度、用意、优点、代价与不适合；给对比与推荐，保留选择权；`docs/style.md`、模板与 evals 同步。
- 页面族约定降为参考，不再作为默认约束；Refine 只提示差异，由使用者决定。
- 方案集新增可选的「风格取向」：只写取向与取舍，不写具体颜色与字体值。
- P4 补「组内只露前几条时给查看更多」；P11 空态补「条件未就绪」（未选区域、未登录）这一态。
- 结构方案编号改为 S1–S16，与设计原则的 P 编号区分；结构测试与 evals 同步。
- 模式收敛为 Audit / Plan / Apply，与其余技能一致；Compose / Refine / Critique / Style 保留为场景与报告类型，默认只出报告。
- 独立代理试跑修正：`SKILL.md` 的「四项代价」改为五项；代价可标「不适用」；容器形态补定义；S10 的「分区带」改名「问题分区」，避免与 S4 分组混读。
- 明确营销 / 官网页边界：首屏叙事与故事顺序不在方案库，只给单元、分区与密度建议；页面族约定只适用列表型与表单型页面。
- B 级重排限定在页内，不改导航与信息架构；容器宽度等事实缺失时标「按假设推得」及其影响。
- 先定目标再定关系；补关系判定顺序与「一页多组关系分别判断」，避免目标与关系互为前提。
- 一致性默认只评页内，没有同族页面输入时写「仅页内」；S3 适用放宽到 3 条以上；编号索引标明 S1–S10 结构、S11–S13 状态、S14–S16 适配。
