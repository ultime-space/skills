# 方案集模板

````md
# <页面 / 区块> 结构方案

## 范围

- 内容关系：单条对象 / 同构集合 / 比较集合 / 主辅 / 序列 / 录入 / 异构聚合
- 优先目标：找 / 比 / 扫 / 读 / 填
- 固定项：<不可动的字段、顺序、元素>
- 最坏内容：<最长文案、条目上限、空数据、译文增长>
- 容器：<宽度区间；降级点由容器宽度决定>
- 范围级别：A 排列级 / B 结构级（需同意）

## 诊断

- 症状：平 / 挤 / 散 / 没重点 / 找不到入口
- 具体位置：<哪一块、哪一行>
- 不属于本次的问题：<例如对比度、状态语义>

## 方案 A：<结构名>

- 结构：<行 / 卡 / 块 / 区 / 表 / 轴；单列 / 双列>
- 线框：

```text
<只画结构，不超过 8 行>
```

- 改动点：<排列方向 / 主次 / 分组 / 对齐 / 密度 中的哪几项>
- 预期：<解决扫描效率 / 层次 / 信息量>
- 代价：可比较性　一屏信息量　定位成本　最坏内容风险　一致性
- 页面族约定：<新增 / 条目操作 / 筛选 / 提交 / 危险操作各在哪个槽位；与约定是否冲突>
- 窄屏：<退法>
- 什么偏好下选它：<一句话>

## 方案 B：<结构名>

## 方案 C：<结构名>

（同上；至少两套，最多三套）

## 推荐

- 推荐：<A / B / C>，因为 <目标> 优先。
- 偏好开关：如果你更看重 <X>，就选 <另一套>。
- 组合：本页同时用到 <其它条目>；冲突处按目标裁决。

## 待确认

- 视觉结论需要人看：<哪几点>
- 需要业务侧取值：<哪些位置>
- 与页面族约定的冲突：<无 / 冲突点与影响范围>
- 不在本次范围：<合规评审、状态语义、内容改写>
````
