# New Project（新项目）

## 何时用

从 0 设计架构、技术选型、目录与分阶段计划。

## 输入

- 业务目标 / 页面清单
- 端（mp / app / web / admin）
- 团队规模 / 交付周期
- 已有技术栈约束

## 先读

1. 项目 `AGENTS.md` / `rules/`
2. `../docs/00-constitution.md`
3. `../docs/01-family-cards.md`（只读相关族）
4. `../docs/03-style-map.md`
5. 需要选型时：`../docs/05-patterns.md`

## 步骤

1. 盘点：页面、角色、数据、外部系统。
2. 选规模档位：L0 / L1 / L2。
3. 选环节：Transport / Wrapper / Behavior / State / ...；标明必需 / 可选。
4. 定目录：`apps/` + `packages/`（如果需要）。
5. 定契约：类型来源、命名、门禁。
6. 出分阶段计划：每阶段一个可验收的垂直切片。

## 输出

- 架构图（文字）
- 目录树
- 环节清单
- 分阶段计划
- 风险与未定项

## 停止条件

- 业务目标不清
- 后端契约未知且无法假设
- 需要引入新的外部服务但无人确认

## 验收

- 每条规则引用 A-ID
- 计划可执行、可验收
- 不含敏感信息
