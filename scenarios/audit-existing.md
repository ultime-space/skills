# Audit Existing（旧项目审计）

## 何时用

接手 / 升级 / 重构前体检。

## 输入

- 仓库路径 / 分支
- 目标（升级、拆分、迁移、只体检）

## 先读

项目规则 → 宪法 → 相关族卡 → 现有 `README` / `docs`

## 步骤

1. 盘点：技术栈、目录、页面、请求层、状态、类型、测试。
2. 逐条对照 A1–A21；标 pass / warn / fail。
3. 找“历史实现”与“环节缺失”：哪些是习惯，哪些是必需。
4. 出差距清单：影响、成本、优先级。
5. 出升级计划：分阶段、可回滚、每阶段验收。
6. 风险：兼容、数据、权限、发布。

## 输出

- 体检报告
- 差距清单（severity）
- 升级计划
- 回滚方案

## 停止条件

- 无法只读访问
- 需要改动生产配置
- 发现密钥 / 隐私：停止并提示轮换

## 验收

- 只读；不改代码
- 每条结论有文件路径 / 命令 / A-ID
