# AI 生成契约 v0

> 2026-10-26 · v0 草稿。
> 用途：所有模型 / agent 生成或修改代码前先读；与《代码宪法 v0》《代码族卡 v0》配套。
> 术语：English（中文）。

## 1. 先读

1. 《代码宪法 v0》
2. 相关《代码族卡 v0》
3. 设计架构时：`06-architecture.md`（档位 / 七步法 / 边界 / ADR）
4. 需要选型时：`05-patterns.md`（按力选，不按名字选）
5. 项目覆盖：`AGENTS.md` / `rules/` / `README`
6. 相关契约 / 类型 / 测试 / 示例

## 2. 禁止

- 禁止新增 token / 组件 / API 而没有真实消费方。
- 禁止新增运行时依赖而不说明体积与必要性。
- 禁止把业务逻辑放进 Transport（传输层）或 Page（页面）。
- 禁止制造第二份真源（手写会漂移的文档 / 类型 / 常量）。
- 禁止注释复述代码。
- 禁止手改生成物。
- 禁止空 catch / 静默失败。
- 禁止跨族复制而不登记母版与分叉点。
- 禁止复制项目门禁（如 `kit:check`）；只通过 config 调用。
- 禁止在 Plan 模式改文件；只输出计划。
- 禁止把密码 / 密钥 / 令牌 / AK/SK / 连接串 / 客户隐私写进代码、文档、示例或提示词；发现即脱敏并提醒。
- 禁止外部文档引用内部文档 / 内部路径 / 内部主机名。
- 安全红线不可豁免；不得以例外登记绕过。

## 3. 文档安全

- 文档分级：`Public（公开）` / `Internal（内部）` / `Confidential（机密）`。
- 外部文档自包含；不出现内部链接、路径、主机名、系统名。
- 内部文档标 `Internal`；不进入交付目录。
- 生成示例值用占位符（`<TOKEN>` / `<PASSWORD>`），不得复制真实配置。
- 发现疑似密钥 / 隐私，停止生成、脱敏、提示轮换。
- 术语格式：英文首次出现用 `English（中文）`；代码标识符保持英文。

## 4. 必须

- 说明改了哪些文件、为什么（引用 A1–A21）。
- 跑项目验证命令，报告命令与结果；不能跑要说明原因。
- Apply 前后跑项目门禁；Audit 先跑内置规则，再跑 config gates；不得跳过失败。
- 新增例外必须写理由 + 主人 + 到期。
- 注释只写意图 / 契约 / 边界 / 反例 / 警告。
- 状态用联合类型；switch / map 穷尽。

## 5. 输出格式

1. **改了什么**：文件列表
2. **为什么**：规则 ID（A1–A21）
3. **怎么验**：命令 + 结果
4. **风险 / 不确定**
5. **后续**：owner + 到期

## 6. Review Checklist（评审清单）

- [ ] 族形正确（Page / Behavior / Transport）
- [ ] 依赖向内
- [ ] 状态穷尽
- [ ] 错误可见
- [ ] 注释只消歧义
- [ ] 生成物未手改
- [ ] 例外已登记
- [ ] 无敏感信息 / 无内部路径外泄
- [ ] 验证命令通过
